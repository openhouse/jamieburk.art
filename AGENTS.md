# AGENTS.md

Build a small, deployable portfolio for Jamie Burkart using Next.js App Router, TypeScript, MDX, Tailwind CSS, daisyUI, npm workspaces, and Dokku Dockerfile deployment.

## Commands
- Install: `npm install`
- Develop: `npm run dev`
- Check before finishing: `npm run check`
- Build: `npm run build`

## Content safety
Do not publish private health, therapy, financial, family, residency, coalition, client, legal-review, analytics, raw transcript, stakeholder-list, credential, or unapproved photo material. When uncertain, write: `TODO: Jamie approval required before publishing this detail.`

## Style
Keep V1 calm, editorial, civic-minded, accessible, and technically credible. Use Broadway blue `#0b5f81`, warm off-white `#eeefec`, ink `#343435`, muted gray `#5e5f61`, and surface `#fffdf8`.
