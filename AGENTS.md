# AGENTS.md - Jamie Burkart Portfolio

## Mission

Build a small, public-safe, Next.js portfolio site for Jamie Burkart.

The site should make this sentence believable:

> Jamie Burkart builds operating structure for ambiguous public-facing technical work.

## Do

- Use Next.js App Router.
- Use TypeScript.
- Use Server Components by default.
- Use MDX for case-study content.
- Use Tailwind CSS and daisyUI with Jamie's custom theme.
- Keep pages static-first.
- Keep privacy boundaries visible.
- Prefer clear public-safe summaries over raw archives.
- Keep the Docker/Dokku deployment path working.

## Do Not

- Do not add a database.
- Do not add a CMS.
- Do not add authentication.
- Do not add an AI chatbot.
- Do not expose private transcripts, raw notes, coalition archives, client materials, or personal crisis context.
- Do not commit private fonts.
- Do not use unapproved photos of people.
- Do not make Source-Backed Team Memory sound like production SaaS.

## Voice

Plain claim first.
Beautiful sentence second.
Proof nearby.
