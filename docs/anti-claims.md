# Anti-Claims

This file is a public-safe pointer for the anti-claims register.

Canonical anti-claims live in `docs/knowledge-bank/anti-claims.md`.

Use that register before strengthening public copy. If a claim would imply sole
ownership of collective work, current official status for an archived prototype,
private-source availability, legal authority, autonomous AI judgment, or access
to private records, do not publish it without explicit review.
