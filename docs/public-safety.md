# Public Safety

This repo is public. Nothing committed here should surprise Jamie, expose a
collaborator, publish private records, or create a claim that cannot be defended
from approved public-safe evidence.

## Public Site Rule

The site is a composed portfolio, not a public knowledge-bank browser. Do not
add public routes named `/proofs`, `/knowledge-bank`, `/public-claims`, or
similar.

## Never Commit

- raw transcripts or private Otter exports
- private coalition notes
- legal-review material
- client-private data
- private screenshots
- unapproved photos, participant names, quotes, or stories
- private fonts
- credentials, keys, certificates, API tokens, or `.env` files
- private financial, health, legal, property, or family material

## Production Gates

Production preflight fails on visible TODOs, placeholder resume language,
missing public contact email, private/proprietary font files, committed env
files, private source directories, likely secrets, raw transcripts, staging URLs
in production metadata, and non-explicit robots policy.

Staging may warn on approval-sensitive content, but it must still fail on
secrets, private font files, placeholder resume, and private source directories.

## Claim Discipline

Use the knowledge bank first. Public copy should never strengthen a claim beyond
its source basis, status, guardrail, and protected boundaries.
