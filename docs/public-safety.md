# Public Safety

This site is a public-safe professional proof surface. It should support referrals and applications without exposing private working material.

Do not publish:

- private notes, private emails, private correspondence, or raw transcripts
- health, financial, banking, tax, trust, legal, therapy, or debt details
- private coalition notes, legal-review materials, stakeholder lists, unapproved names, or unapproved photos
- credentials, private URLs, private screenshots, internal dashboards, customer data, vendor terms, or secret configuration
- private font files or unlicensed commercial fonts

Use collective-work language where appropriate:

- `co-built`
- `supported`
- `stewarded`
- `contributed to`
- `helped structure`

When a detail might be useful but is not approved for public release, keep it out of the page or mark it:

```text
TODO: Jamie approval required.
```

The public-safety script is a reminder system, not a substitute for judgment. Run `npm run public-safety` before launch and before adding new case-study material.
