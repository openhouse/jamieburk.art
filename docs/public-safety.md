# Public Safety

The canonical public-safety guidance lives in
`docs/knowledge-bank/public-safety.md`.

For launch, the public site may contain composed, public-safe proof claims,
guardrails, and protected-boundary summaries. It must not contain raw source
materials, private records, credentials, private paths, raw transcripts, private
correspondence, private screenshots, or collaborator-sensitive details without
explicit approval.

Run:

```bash
npm run public-safety
```
