# Portfolio Blind-Spot Register

The structured control is
`docs/knowledge-bank/data/portfolio-blind-spot-register.json`. It converts the
current portfolio blind spots into durable eval inputs without pretending that
external review has already happened.

Every row is `protocol-ready` and `required-not-run`. No human result is
inferred from the automated score. Completion evidence remains empty until a
real job description, unfamiliar reviewer, collaborator, editor, rights
reviewer, application record, repository owner, or production check supplies
the required evidence.

## Reading The Score

A passing blind-spot hard gate means the operating contract is explicit and
internally consistent. It does not mean the underlying market, human,
collaborator, visual, application, merge, or production result has passed.

The automated evaluator therefore checks for all of the following:

- an owner and a named risk;
- at least three evidence requirements;
- a criterion-specific anti-gaming rule;
- a stop rule and next action;
- an exact manual-gate link;
- `completionEvidence: []`; and
- no private paths or authenticated-session material.

Human completion belongs in a later, reviewed update with dated evidence. Until
then, preserving `required-not-run` is a successful truth condition, not a
defect to conceal.
