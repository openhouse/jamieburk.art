### Public-Safe Archive Summary

Aggregate or summarized knowledge derived from private records without exposing
the private records, private paths, names, contact lists, raw transcripts,
attendance records, private rows, screenshots, or correspondence.

Google Shared Drive records use the same rule. A protected source record may
name a public-safe artifact class, date, supported propositions, non-support
boundaries, and an opaque locator. It must not expose Drive or file IDs, private
URLs, folder paths, sharing state, contact data, or raw content. Shared Drive
custody does not establish authorship, adoption, or impact; revision metadata
that names a last modifier supports maintenance attribution only. The selective
2026 pass is documented in
`docs/knowledge-bank/projects/google-shared-drives-production-2026-07-14.md`.
