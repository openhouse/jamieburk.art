# Role Fit: Source-Backed Team Memory

This page maps Jamie's knowledge-systems work to documentation, decision memory, and AI-assisted team-memory contexts.

It is generic and public-safe. It does not name private companies, private calls, active job opportunities, or individual conversations.

## Core Claim

Jamie helps teams preserve decisions, meeting context, open questions, source trails, and onboarding knowledge so valuable ideas do not disappear after the conversation.

## Use Public-Safe Language

Use:

- decision memory
- source-backed notes
- meeting-to-memory workflow
- open-question register
- onboarding context
- human review
- source-linked documentation
- AI-assisted summarization with accountability

Avoid:

- private Wikipedia
- roleplay personas
- private archive browser
- AI replacement for judgment
- finished SaaS
- omniscient memory layer
- broad private archive ingestion

## Boundaries

Source-Backed Team Memory is an early method / proof-of-practice. It should not be framed as a finished SaaS, autonomous publication system, legal/medical advice system, compliance product, or replacement for human judgment.
