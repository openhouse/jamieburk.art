# Typefaces

Use safe web fonts only through `next/font/google`.

## V1 Direction

- Karla: body, UI, prose.
- Archivo Narrow: display headings, compact metadata, proof labels, and
  eyebrows.

## Do Not Commit or Serve

- Trade Gothic
- Verlag
- Gotham Rounded
- RISQUE
- the Maria handwriting font
- any private, proprietary, or unlicensed `.ttf`, `.otf`, `.woff`, or `.woff2`
  files

Typography is not allowed to block the safety/knowledge-bank portion of the PR.
If a font change creates a build or visual problem, document it and keep the
existing safe web-font system.
