# Yehuda Katz

Ember's public team page lists Yehuda Katz on its Steering Committee and
Framework Core Team. An official Ember Team article describes community
leadership through consensus, persuasion, shared direction, peer teams, and
clear coordination responsibilities. This record uses those public materials
to ask how conventions and proposal review can help a system evolve without
discarding accumulated knowledge or breaking existing practice.

## Design question

Can conventions make the common path legible while a proposal-and-review
process lets the system change without discarding accumulated knowledge or
breaking existing practice?
