## Method And Control

The two access surfaces were complementary. The authenticated web interface
established the current folder controls and made slowly hydrating items
inspectable. Local materialization supported searchable close reading and file
verification. No session data, private link, or local filesystem path enters
the knowledge bank.

- 15 project packets inside Jamie Projects History's `jamie-projects` folder;

These are mutable interface observations, not fixed lifetime totals. A file
not materialized locally is not absent. A page not recovered in this pass does
not mean it never existed.

## Privacy And Publication Boundary

No raw private document, private filename inventory, local path, contact data,
phone number, correspondence, transcript, coalition note, legal or financial
record, participant record, credential, authenticated response, or browser
session material enters this public repository.

No new reserve claim is automatically projected onto the website. Future
promotion requires a current audience need, claim-level source review,
collaborator and credit review where relevant, and media rights approval.
