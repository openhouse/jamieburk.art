# Portfolio Effectiveness

Reviewed: July 15, 2026

## Purpose

The citation, launch, and knowledge-bank suites answer whether the repository is
internally consistent, public-safe, buildable, and careful about evidence. This
suite asks a different question:

> Does that careful record help the intended reader understand Jamie, trust the
> work, and make a timely hiring decision?

The seven criteria preserve the largest present blind spots as measurable work.
Passing at the local evidence floor means the repository has a usable protocol,
truthful evidence state, and explicit next action. It does not mean every
external dependency is complete.

Scores below 5 are deliberately visible. They identify evidence that cannot be
self-certified by Jamie, Codex, another LLM, a browser script, or the repository
itself.

## 1. Hiring-Reader Comprehension

Five task cases cover an OTI or civic-technology hiring manager, a recruiter,
an implementation director, a civic-technology product leader, and a past
collaborator reviewing care and credit. Each case records its timebox, routes,
questions, and required public signals.

Automated source and browser checks may verify that the role, resume, contact
path, case-study structure, and boundaries are present. They cannot establish
that a real reader understood them. A score of 5 requires at least five real
sessions stored only as privacy-safe aggregate outcomes. Do not commit reviewer
names, contact details, recordings, or raw notes.

## 2. Collaborator Corroboration

The first request queue covers five high-value attribution gaps:

1. Harry J. Epstein Company: decision scope, cross-functional coordination,
   and operational change.
2. NYC Artist Coalition: formation, event production, digital operations, and
   coordination inside collective work.
3. WOW List: product, infrastructure, support, adoption, and shared authorship.
4. KC Town Hall: general-contractor coordination, field sequencing, and the
   neighborhood process.
5. KC Spaces Fund: behind-the-scenes web implementation and naming-system work
   without public-organizer inflation.

Each request asks what problem was present, what Jamie was responsible for,
what changed, what remained collective, and what permission applies. Permission
states are private background only, public paraphrase approved, public quotation
approved, and do not use. Silence is not permission. AI-assisted archive review
is not a human collaborator proof note.

## 3. End-to-End Operating Narratives

Three normalized sequences now connect:

```text
condition -> diagnosis -> intervention -> coordination -> changed behavior -> outcome
```

The first set covers CallNYC, KC Town Hall, and NYC Artist Coalition / Commercial
Rent Stabilization. Each sequence links to proof, claims, a public route, and at
least three causal or collective-work boundaries. Outcomes stay as narrow as
their evidence: intended audiences do not become engagement, appropriations do
not become receipt, and collective government outcomes do not become Jamie's
sole accomplishment.

## 4. Current 2024-2026 Evidence

The first current-practice layer retains:

- 2025-2026 Commercial Rent Stabilization coordination, source lineage, public
  data, and campaign-memory work;
- the 2026 source-backed team-memory method and pilot design, explicitly not a
  claim of delivered client work;
- the 2026 public portfolio's citation, safety, archival-production, and eval
  implementation, explicitly self-directed rather than external adoption.

These records make current practice inspectable without pretending that the
date of an archival review makes every historical project recent. A score of 5
requires externally corroborated current outcomes.

## 5. Consent-Cleared Visual Proof

The CallNYC project mark is the present cleared artifact. Five additional
selection lanes cover KC Town Hall, NYC Artist Coalition, WOW List, Commercial
Rent Stabilization, and Sunday Dinner / 196.

No candidate counts as cleared until source, rights, represented people, crop,
credit, alt text, caption boundary, and publication context are approved.
Candidate records contain no local archive path, participant identity, or
unapproved image.

## 6. Exact-SHA Release Evidence

The release criterion points to `launch-blockers.md` and requires one exact SHA
to carry repository checks, dependency review, Docker, staging, responsive and
accessibility QA, Jamie's approval, deployment identity, and production smoke
evidence. A branch pass or nearby commit earns no promotion credit.

This feature branch intentionally records no verified production candidate.
That evidence can exist only after the exact commit is reviewed on staging.

## 7. Maintenance

Ownership is separated across public truth and composition, technical release
evidence, and public-safety / collective-credit review. Source health,
collaborator proofs, visual rights, reader validation, and eval complexity each
have a maximum review cadence.

The suite allows no public routes, frameworks, or more than ten criteria. A
quarterly retirement review should merge or remove criteria that no longer
change a decision. Difficulty is not a reason to delete a gate, and an
evaluator's assertion is never independent evidence for its own score.

## Commands

```bash
npm run check:portfolio-evals
npm run test:portfolio-evals
npm run report:portfolio-evals
```

The root `npm run check` includes the check and adversarial tests.

## Current Stop Condition

The local hill climb stops when all seven criteria meet their minimum and the
weighted target passes twice consecutively. Real reader sessions, collaborator
responses, additional rights-cleared artifacts, external current outcomes, and
exact-SHA production evidence remain explicit queues until they actually occur.
