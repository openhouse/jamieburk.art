# Source Classes

Use source classes to describe support without exposing protected evidence.

## public-source

Public web pages, public records, public campaign materials, press, or public
project pages that can be linked or cited after review.

## approved-resume

Claims that appear in Jamie's approved résumé. Résumé-backed claims can still
need surface-specific review before appearing on the homepage.

## approved-artifact

An artifact Jamie has approved for public display, such as a screenshot, PDF,
diagram, or public handout.

## public-safe-summary

A summary written from private or mixed source material where the underlying
records should not be published.

## private-source-outside-repo

Private materials Jamie may use for personal verification but that must never be
committed here.

## collaborator-review-required

Collective-work claims, named-collaborator claims, screenshots, quotes, and
community records that require explicit review before publication.

## do-not-publish

Material that must not appear in the repo or website: credentials, private
correspondence, private contact records, legal-review materials, raw community
records, private source files, unapproved photos, and client-private details.
