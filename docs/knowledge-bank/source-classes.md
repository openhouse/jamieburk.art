# Source Classes

Use source classes to describe evidence strength without exposing private source material.

| Source class | Meaning | Public handling |
| --- | --- | --- |
| Public source | Publicly available source that can be cited or linked. | Can support public copy when the wording matches the source. |
| Public website | A live or archived public website. | Can support existence, public positioning, and public artifacts. |
| Published article | Press or public article. | Use only after confirming the exact citation. |
| Public government record | Public agency, legislative, budget, or record material. | Use exact wording and avoid overclaiming causality. |
| Resume-backed claim | Claim already present in an approved resume. | Use conservatively and keep resume approval status visible. |
| Private supporting material, not publishable | Material Jamie may use for private verification but should not appear in the repo. | Summarize only at the source-class level. |
| Collaborator-approved material | Material cleared by relevant collaborators. | May appear within approved scope and attribution. |
| Candidate claim, needs review | Plausible claim that needs better source notes or approval. | Keep out of prominent public copy. |
| Protected material | Material withheld for privacy, consent, client trust, law, civic sensitivity, or community safety. | Do not publish. |
