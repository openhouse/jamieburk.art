# Visual Corroboration

This register records public-safe findings from visual archive review without
publishing photographs, identifiers, private paths, or private metadata.

Visual corroboration is a supporting evidence layer. It may establish visible
setting, material conditions, the existence of an artifact, or Jamie's visible
presence in a context. It does not independently establish authorship,
causation, outcome, consent, endorsement, or publication rights.

The canonical structured register is
`apps/www/src/data/visual-corroboration.ts`. Proof claims link to these records
through `visualCorroborationIds`.
