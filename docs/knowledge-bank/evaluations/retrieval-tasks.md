# Knowledge Wiki retrieval tasks

These are human evaluations, not automated claims of comprehension. Record a
future participant's success or failure, time, pages visited, wrong turns,
coaching, and trust only after the task is actually run.

## Orientation

1. Starting from the [Knowledge Wiki root](../README.md), find the current
   CallNYC chronology.
2. Find the source supporting January 30, 2016, from 1 to 3 p.m.
3. Find the correction to the earlier CallNYC years.

## Evidence and boundaries

1. Find the strongest source supporting Jamie's independent development of
   CallNYC.
2. Explain what the Digital District photograph supports.
3. Explain why the photograph is not publicly projectable.
4. Find what the Wiki must not imply about CallNYC and the Council.

## Professional use

1. Find a project demonstrating public-data translation.
2. Find Jamie's Technical Operations proof map.
3. Find the records projected into the Technical Operations opportunity lens.

## Authoring task

Add a fixture page, link it from the pilot index, move it with VS Code's safe
rename, and confirm that its stable ID remains unchanged while links, fragments,
and `canonical_path` are updated. This task remains `not-requested` until a human
teammate performs it.
