# Layout D Homepage East River Curatorial Proposal

The studio began with a visitor problem: can the first viewport make Jamie
present, memorable, and situated in public life while immediately telling a
stranger what he does?

The blind pass was completed before the fuller attribution and recollection
context was introduced. The contextual pass changed the provenance and research
questions, but did not require the image to carry professional or historical
claims. The composition, not the isolated photograph, remains the evaluative
object.

The proposal advances the East River frame for branch and staging review. It
does not close production, source-binding, permission-reinspection, crop, or
indexing gates.

The source parent identifies the first authored implementation commit. Current
candidate identity is carried by the exact file-set fingerprints and browser
receipt; it is not represented as a self-referential Git commit.
