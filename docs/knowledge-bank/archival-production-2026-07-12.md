# Teams Archival Production - 2026-07-12

## Purpose

This pass treats Jamie's working archive as an evidence-development system, not
as a public document browser. It asks which records make Jamie's role, judgment,
implementation practice, scale, or usable outcomes more legible for hiring and
collaboration.

## Archive lanes

### Jamie Projects History

Used as a curated project-evidence layer. Close reading followed the overview
into public captures rather than treating every private message or media file as
equally probative.

  starting point, human-powered construction, participatory design, and
  1,000-plus-mile scale.

### CRS

### job-hunt

Used as an editorial routing layer. The current resume and context outline helped
rank evidence by its usefulness for technical project management, product
operations, civic implementation, and source-backed knowledge-system roles.

Results:

- Selected the public-data pilot for the FairRentNYC case study because it shows

## Collection limits

- This was a selective, high-signal pass, not an exhaustive inventory.
- iCloud hydration can delay or prevent a file from becoming readable during a
  bounded review window.
- A record that did not materialize was treated as unavailable, not nonexistent.
- Raw local paths, private correspondence, stakeholder records, legal-review
  context, transcripts, and private proposal details remain outside the public
  registry.
