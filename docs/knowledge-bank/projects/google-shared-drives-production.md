# Google Drive Shared Drives Archival Production

**Run date:** 2026-07-14  
**Status:** First professional-relevance pass complete; protected research queue open  
**Public route:** None

## Purpose

Jamie maintains project-specific Google Drive Shared Drives so work can move
between devices and be handed off with collaborators. This pass tested whether
that operating practice contained public-safe evidence worth adding to the
knowledge bank.

The result is not a public mirror of Google Drive. It is a bounded provenance
layer: source summaries, atomic observations, claims, anti-claims, research
tasks, and explicit exclusions.

## Corpus Boundary

- 110 Shared Drives were accessible to the authenticated account at review
  time.
- 14 professionally relevant drives received top-level review across eight
  public-safe project families.
- Seven text artifacts and four revision histories received closer review.
- 96 accessible drives remain unreviewed and are recorded as a protected
  research queue, not as absent or unimportant.

Drive IDs, URLs, memberships, permissions, private excerpts, collaborator
emails, and raw file inventories are not stored in this repository.

## Review Method

1. List Shared Drives through the authenticated Google Drive connector.
2. Select project and organization drives with clear professional relevance.
3. Inspect direct children and selected second-level anchors.
4. Fetch text only for bounded artifacts with likely role or workflow value.
5. Use revision history where attribution matters.
6. Decompose each retained source into atomic observations with limitations.
7. Promote only direct, useful, public-safe actions; route incomplete material
   to tasks and exclude sensitive material.

## Promoted Claims

### `CLM-GDRIVE-PORTABLE-HANDOFF-PRACTICE`

Jamie maintains project-specific Shared Drives as portable handoff surfaces
across devices and collaborators. The reviewed sample contains structured
onboarding templates, source-backed running memory, action-oriented guidance,
and privacy-aware archive tooling.

This is selected for Technical Operations. It does not imply that Jamie owns or
authored every accessible drive or file.

### `CLM-196-RESIDENCY-ONBOARDING-HANDOFF`

A Jamie-attributed 2023 template turns residency acceptance into an operational
handoff: schedule, pre-arrival orientation, space configuration, and independent
collaborator access. It is selected for the 196 / Sunday Dinner case study.

The source does not prove the separate 20-plus-resident scale claim and does not
authorize participant identification or quotation.

### `CLM-NYCAC-MULTI-ACTION-GUIDANCE-DRAFT`

An October 2025 revision attributes to Jamie a coalition draft that organized
three concurrent civic lanes into concrete audience actions. A later revision
belongs to a collaborator. The claim is selected for the Fair Rent NYC case
study as draft and communication-design evidence, not publication or outcome
evidence.

### `CLM-GDRIVE-ARCHIVE-OVERVIEW-WORKFLOW`

One stored Drive revision attributed to Jamie contains a reusable shell workflow
for mixed-format project overviews: directory inventory, PDF extraction with OCR
fallback, tracked-document conversion, large CSV/JSON sampling, skip rules, and
an explicit sensitive-output warning. It is selected for Technical Operations.

The review inspected code paths; it did not run the workflow against every file
type or publish the protected script.
