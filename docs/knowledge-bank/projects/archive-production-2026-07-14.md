# Working-Archive Production - July 14, 2026

## Scope

This pass close-read three long-running iCloud working archives:

- Jamie Projects History;
- Commercial Rent Stabilization (CRS);
- job-hunt.

The production method began with each archive's overview or current anchor
document, then narrowed to authored artifacts, public-source captures, approved
professional materials, and records that could resolve an existing proof gap.
Files that had not materialized locally were not treated as read. Folder
association alone was not treated as authorship.

The public repository contains only public-safe metadata, source relationships,
bounded claims, and opaque protected-locator IDs. It does not contain private
paths, correspondence, contacts, raw coalition records, legal-review material,
pricing, or family context.

## Editorial Decision

Archive production is cumulative; site composition is selective. This pass
strengthens existing CRS and source-backed-memory pages while retaining the
newly mature creative-technology claims in the bank. No new work card was added.
That is a compositional decision, not evidence loss.

Every future pass should preserve the same sequence:

1. intake the fragment;
2. decompose the source into bounded observations;
3. connect evidence to a claim or inquiry;
4. record what the source does not establish;
5. mature only what the evidence supports;
6. select a public projection only when it helps the audience and purpose.
