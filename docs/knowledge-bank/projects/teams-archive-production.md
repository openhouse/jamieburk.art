# Teams Archive Production

Status: bounded archival-production pass completed July 14, 2026 and
reconciled against authenticated iCloud Drive on July 15. Selected claims were
promoted to the Fair Rent NYC case study; deeper material remains in the
knowledge bank.

## Scope And Method

This pass close-read materialized working records from three cloud-backed
project corpora: `Jamie Projects History`, `CRS`, and `job-hunt`. It used each
corpus's overview or current working document as an anchor, followed specific
high-value source trails, and normalized only what was actually readable.

The July 15 reconciliation used the authenticated iCloud Drive web interface
to inventory the same three corpora when local materialization remained slow.
It compared web-visible folder metadata with materialized overview documents
and separately recovered source bodies. Web visibility established recovery
state and archive architecture; it did not make an unread file readable.

The public repository contains source metadata, atomic observations, bounded
claims, and research state. It does not contain raw transcripts, correspondence,
contact details, private strategy, legal-review context, vulnerable business
information, or local filesystem paths.
