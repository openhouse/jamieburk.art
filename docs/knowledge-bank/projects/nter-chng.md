# NTER CHNG

NTER CHNG was an interactive texting installation by Drew Bolton, Jamie
Burkart, and Garrett Fuselier. Audience messages entered a shared visual field,
making the installation an early example of Jamie's collaborative
participatory-systems practice in interactive media.

The project-authored record dates the original Cocoon Gallery presentation to
January 2010. It was later included in the Kansas City presentation of
*America: Now and Here* in May 2011. The restaging required coordinated work
across software, hosting, display hardware, networking, wiring, fabrication,
installation testing, gallery adjustment, and teardown.

## Present-grounded source return

The July 19, 2026 encounter returned to the archived project site, exhibit
