# The People's Money

As observed October 18, 2026, the [October 15 official announcement](../sources/nyc-cec-peoples-money-cycle5-2026-10-15.md) places Cycle 5 in idea generation. Its later assembly, vote and implementation stages should not be confused with Cycle 4, which is beginning implementation.

The operating sequence joins community ideas, deliberation, voting and delivery by community organizations. The program page is [participate.nyc.gov](https://www.participate.nyc.gov/). Use the dated source for exact windows before taking action.

Hillary Carelli-Donnell is publicly identified as the program director; Alexis/Lexi Spencer's biography describes management of PB projects with nonprofits. These provide role context, not proof either person hires for the opportunity.
