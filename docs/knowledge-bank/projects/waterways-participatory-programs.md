# Waterways and participatory programs

Status: developing knowledge cluster, not selected for website projection.

This cluster preserves public evidence and open questions about Jamie's early
participatory practice across galleries, domestic spaces, river expeditions,
and river-city public programs. It does not assume that every project used the
same method or produced the same result.
