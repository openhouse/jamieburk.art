# WOWList

## Project

WOWList was a co-built community-calendar and social-discovery platform for
arts, music, and local-interest scenes. Followable keyword communities turned
the terms organizers already used into event publishing and distribution
surfaces.

## Jamie's Bounded Role

Jamie co-built and supported the product model, event workflows, and
public-facing web system. He also confirms establishing the shared `@wowlist`
account as project identity infrastructure. The public account does not reveal
which teammate composed each individual post.
