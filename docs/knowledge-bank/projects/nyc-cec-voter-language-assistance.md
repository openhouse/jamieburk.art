# CEC Voter Language Assistance

The [CEC homepage](https://www.nyc.gov/site/civicengagement/index.page) identifies poll-site interpretation for limited-English-proficient New Yorkers as a core function. The [volunteer page](https://www.nyc.gov/site/civicengagement/get-involved/volunteer.page) also describes language-assistance outreach and support.

This is separate from voting in The People's Money. Election-specific sites, dates and available languages must be checked against the current program information before directing a resident. The graph does not infer staff assignments or Jamie's language qualifications.
