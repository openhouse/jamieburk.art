# Jamie and WOW List Facebook event archival production

**Reviewed:** 2026-07-16  
**Surfaces:** Jamie Burkart's authenticated current Past Events index and the
WOW List Facebook Page Past Events surface

## What was reconciled

Two independent traversals of Jamie's current Past Events interface produced
the same 511 occurrence keys across 502 canonical event pages. Nine rows carry
occurrence-specific identifiers, and four canonical pages account for those
recurring-event rows. Each traversal ended with 18 consecutive terminal
observations that added no canonical event page. The sorted occurrence-key
digest matched across both runs.

This is 100 percent capture-date **index-population reconciliation**. It is not
a native Meta owner export, a deletion history, a complete event-body crawl,
or proof of every event that ever existed. The repository retains aggregate
controls, a population digest, selected organization labels, and three
mission-relevant event summaries. It excludes the reconstructable personal
timeline.

The index spans records dated from December 2006 through August 2023. Organizer
labels were populated on 455 rows and unavailable on 56. Twenty cards
explicitly displayed Jamie Burkart as organizer, and 21 displayed NYC Artist
Coalition. These are bounded card-level labels, not a complete production
history.

## Traction and stakeholder boundaries

The index cards did not display response labels. Three selected detail pages
did, but those values are mutable event-level interface labels, not attendance,
unique people, reach, endorsement, mandate, or impact. The 200th Sunday Dinner
page's displayed component counts did not reconcile to its aggregate response
label, so no response total is selected for public use.

Selected public organizer labels point toward cultural-space, coalition,
city-agency, public-official, housing-advocacy, and arts-organization research.
They do not prove Jamie attended, collaborated, was endorsed, or caused an
outcome. Each is a source lead requiring event- and project-specific
corroboration.

## URLs and source routing

The population contained 502 distinct current event-page routes. The index
cards did not expose event-body outbound links, so this pass makes no claim to
100 percent body-level article or posted-URL recovery. That work remains an
explicit source-maturation queue rather than a silently dropped category.

## WOW List result

In authenticated Page context, the capture-date WOW List Past Events surface
displayed `No events to show`. Exact WOW List title and organizer matching in
Jamie's fully reconciled current index also returned no event record.

This means only that no WOW List event record was recovered by this bounded
pass. It does **not** mean WOW List never created, hosted, cohosted, or
circulated a Facebook event. A Page owner export, direct event links, archived
captures, and collaborator records remain appropriate next research routes.

The current public WOW List profile does preserve the project's own mission
language: an event-sharing tool and community-building project with the motto
"Being there changes everything." That language is selected for the WOW List
case study as first-party purpose, not independent proof of adoption or impact.
