# Opportunity-Discovery Benchmark

The discovery benchmark asks whether Jamie's trajectory can retrieve fitting
roles without relying on an exact title. It combines capabilities, operating
patterns, work conditions, salary, and location.

The committed fixture includes:

- six known-good, officially verified priority roles;
- one adjacent program-operations scenario;
- false-positive controls for salary and unrelated operations scope;
- hard-screen controls for required licensure and deep specialist coding;
- a closed-role control.

The scenarios are evaluation fixtures, not live job leads. Their purpose is to
test title-blind recall, precision, hard-screen detection, and freshness. Only
officially verified opportunity records may surface as live.

Run `npm run wiki:discovery` to regenerate the diagnostic report.
