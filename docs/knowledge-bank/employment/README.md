# Employment Context

This hub connects the present-tense job search to the existing Knowledge Wiki
without making private application activity or raw communications public.

The immediate professional category is **Technical Project Manager - Product
Operations & Implementation**. That frame is a useful hiring translation, not
a final definition of Jamie's practice.

## Working Pattern

Across the strongest records, a repeatable pattern is visible:

1. enter an emerging human, institutional, or technical situation;
2. gather sources and listen for the structure already present;
3. create shared language, requirements, workflows, and decision records;
4. coordinate implementation, launch, onboarding, and correction;
5. leave a handoff that lets other people continue with agency.

## Boundaries

- Official employer pages are canonical for live role facts.
- Aggregators and archived lists are discovery aids only.
- Warm paths, application status, contact history, and raw correspondence stay
  in the Private Source Vault.
- A requirement match is not an employer decision.
- A passing internal evaluation cannot manufacture an interview, referral, or
  human approval.
