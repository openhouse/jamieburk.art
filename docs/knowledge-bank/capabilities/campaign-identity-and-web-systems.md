# Campaign Identity and Web Systems

Jamie helped give public-interest campaigns coherent identities and usable web
surfaces through which people could understand an issue, find a next action,
and return as the work changed.

## System components

- shared visual identity and campaign relationship;
- domains, deployment, and platform continuity;
- issue explanations written for public use;
- calls, testimony, meetings, sign-up, and support pathways;
- structured location, sponsor, partner, press, and resource data;
- forms, reusable modules, social presentation, and maintenance handoffs.
