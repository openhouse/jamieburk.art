# Technical Operations

Technical Operations is the practice of making complex work usable across
people, systems, evidence, decisions, and time. In this portfolio it includes
delivery coordination, risk surfacing, documentation, implementation support,
quality assurance, correction, onboarding, and handoff.

## Pilot proof

[CallNYC](../projects/callnyc.md) demonstrates public-data interpretation,
independent implementation, source-backed correction, and durable archival
continuity. The [Source-Backed Team Memory method](../methods/source-backed-team-memory.md)
demonstrates the same operating discipline as a reusable workflow.

This capability page is a retrieval map, not permission to publish every
connected record.
