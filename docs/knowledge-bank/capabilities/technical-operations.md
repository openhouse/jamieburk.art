# Technical Operations

## Orientation

This capability joins delivery coordination, risk surfacing, decision records,
operating documentation, implementation support, handoffs, and iterative
improvement. It is a professional reading path, not a claim that every project
used the same formal title.

## Evidence Path

[CallNYC](../projects/callnyc.md) demonstrates public-data interpretation and
independent implementation. [Source-Backed Team Memory](../methods/source-backed-team-memory.md)
demonstrates a governed method for turning fragmented records into usable team
knowledge. The [OTI opportunity lens](../opportunities/oti-technical-operations.md)
selects relevant proof without changing the underlying record.
