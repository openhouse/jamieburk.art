# NYC Artist Coalition Public-Meeting Operating System

A surviving coalition playbook defines public meetings as a three-week
operating system spanning partner, participant, elected-official, testimony,
press, web, print, social, video, and day-of workflows.

The source and public event corpus support a collective implementation pattern.
They do not identify Jamie as the playbook's original author, assign him every
task, prove that every step occurred for every event, or establish attendance
and policy impact. The current public projection is held pending attribution
and editorial review.
