# East River Clearance-Scope Correction

The first implementation used the word `cleared` for rights, consent, and
public display at the asset level. Independent review showed that this erased
important distinctions already present elsewhere in the record.

The corrected states say only what is supported: Jamie authorized this exact
public-branch review occurrence; portfolio permission is reported but its
private evidence has not been reinspected in this implementation; represented-
person and final crop review remain open; production and indexing remain open.

The prior wording remains visible here so the correction can teach later
iterations. It is not silently overwritten, and it does not close any human
release gate.
