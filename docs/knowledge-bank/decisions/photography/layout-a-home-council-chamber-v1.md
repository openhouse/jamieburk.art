# Use the Council chamber image for Layout A branch review

The selected image helps a stranger encounter Jamie as a person before reading
the operating proposition. The adjacent role label and concrete outputs carry
the employment argument. The chamber supplies public-institution context, not
institutional endorsement.

The RFC's East River example remains valuable design history. Importing it here
would have changed the chosen donor and obscured which visual candidate was
actually under review.

## Protected absences

Two donor candidates remain outside the public composition after editorial
review: one lacked a sufficiently specific task and project context; one
visibly named an artist whose exact-image approval was not recorded. The
Knowledge Wiki preserves the reasons without publishing the held images or
private source details.
