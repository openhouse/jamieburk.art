# Select the East River photograph as a Layout C candidate

The choice was contextual, not inevitable. The photograph worked because
literal role copy and next actions carried what the image could not establish.
Layout E later chose a different first-person composition. The corrected Layout
C occurrence remains on hold. Both editions remain useful evidence for future
editorial decisions.

## Withdrawal

Remove or replace the app placement, mark the projection withdrawn or revoked,
verify routes and caches, regenerate reports, and preserve this decision record.
