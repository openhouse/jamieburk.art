# Select the East River photograph for the Layout C homepage

The choice is one dated edit, not the inevitable meaning of the archive. The
East River image remains because it makes Jamie present within a public,
material landscape while the typography and writing perform the professional
orientation.

The raft alternative and no-photo version remain legible. A later edition may
choose differently without invalidating this record.
