# Keep the Layout C resume route photograph-free

The résumé is a repeated-action surface. In this edition, the strongest visual
decision is restraint: role, chronology, evidence, and download access remain
uninterrupted. The no-photo state is represented so future agents do not treat
it as unfinished work and auto-fill it.
