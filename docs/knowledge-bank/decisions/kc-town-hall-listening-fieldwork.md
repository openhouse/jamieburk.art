# KC Town Hall listening within fieldwork

The support letter in the proposal bundle is important because it describes a
listening-driven approach while the project's program remained open. Jamie's
first-person account adds the daily relation between site work and neighborhood
encounter, but not every detail has independent corroboration.

The decision is therefore about keeping listening inside implementation, not a
claim that one survey or one project steward represented the neighborhood.
