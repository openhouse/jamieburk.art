# CallNYC: Issue Pathways For Public Data

**Period:** 2016. **Question:** How could a public constituent-services dataset
help a resident recognize an issue and find a plausible next step?

## Supported Reconstruction

The repository and public coverage support an independent resident-facing
interpretation organized around issue pathways rather than a reproduction of
the source table. The Council's later data-release page supplies institutional
context, not product ownership or adoption.

## Unobserved Alternatives

The record does not preserve a formal option workshop, Council commission,
complete user-research protocol, or evidence that Jamie considered and rejected
specific interface alternatives.

## Outcome Boundary

CallNYC became a functioning archived prototype and received public coverage.
It was not an official Council product. The record does not establish Council
adoption, current service accuracy, complete user testing, or measured resident
impact.
