# Knowledge Wiki: Deep Bank And Selective Projection

**Period:** 2026. **Question:** How can the portfolio gain depth from a large
professional knowledge system without becoming an evidence dump or exposing
protected material?

## Chosen Course

The Wiki stores more public-safe structure than the website shows. Stable
records retain evidence relationships, uncertainty, anti-claims, permissions,
and review states. The portfolio selects and composes only what a reader needs
for a current purpose.

## Alternatives And Constraints

This record does not claim every architectural alternative received formal
evaluation. The governing constraints are public safety, collective credit,
reader effort, source integrity, rights, consent, and the need for plain
Markdown and Git review.

## Outcome Boundary

A mature record is not automatically selected. A generated graph is not an
argument. An automated pass is not Jamie's editorial approval, collaborator
consent, rights clearance, application submission, or production observation.
