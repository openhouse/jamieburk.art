## State is part of the link

`HTTP 200` means a meaningful page was reachable on the verification date. It
does not mean a historic service, application, fundraising drive, phone number,
dataset, or campaign status is current. Project links should therefore carry
useful labels such as `Visit WOW List`, `Restored CallNYC archive`, or `KC Town
Hall historical project site` rather than suggesting every destination is an
active service.

The portfolio should keep its internal case study as the explanatory home and
offer the external project as compact, direct proof. A resume may link the
first useful project-name mention when the canonical home helps the hiring
reader, but a Markdown edit is not complete until its styled PDF sibling and
artifact evals are regenerated.

## Excluded from the total

- three alias domains that resolve to canonical project homes;
- Save NYC Spaces while Jamie's implementation credit remains open;
- Jamie's portfolio itself;
- social profiles, GitHub repositories, press PDFs, government pages, and
  cited evidence sites;
- Wayback-only project pages such as NTER CHNG; and
- projects with no recovered or currently reachable canonical home.

## Maintenance rule

Recheck the canonical URL, meaningful rendered content, redirect destination,
surface state, credit basis, and caution language together. A failed check
changes the entry to `unavailable`, `redirected`, `archive-only`, or
`credit-open`; it does not silently remove the project from history.
