# NYC Artist Coalition DCLA formation photo set

## Retrieval hypothesis

This set gathers the held listening-room photograph, the single real-world
event, and the protected formation source return because they help researchers
find one another. Membership is a retrieval hypothesis, not a claim that every
record has the same author, evidentiary status, or publication permission.

Start with the
[event record](../../events/nyc-diy-spaces-dcla-2017-01-27.md), then keep the
[held photograph](../../assets/photographs/nycac-dcla-listening-room-2017.md)
and [protected-source capsule](../../sources/archives/nycac-dcla-formation-source-return-2026-07.md)
distinct.

Related frames improve retrieval; they do not multiply evidentiary weight.
Near-duplicates, screenshots, and platform occurrences may document custody or
circulation while still referring to the same underlying moment.

## What remains open

Recover the audio, speaker research, interactive visualization, photographer,
exact credit, and depicted-person dignity review. No image in this set is
publicly cleared.
