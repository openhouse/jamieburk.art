# Chad Lens: Professional Legibility

Core rule:

> Make Jamie's unusual work institutionally legible without losing purpose,
> agency, dignity, or specificity.

Chad's lens is not about making Jamie sound conventional. It is about removing
reader burden. The reader should not have to decode a civic archive, an artist
practice, a coalition role, or an AI-method note before understanding Jamie's
professional value.

## Checklist

- Purpose: Have we said toward what end the work existed?
- Agency: Is Jamie visible as the actor with an accurate verb?
- Legibility: Would a public-sector, HR, recruiter, or technical-operations
  reader understand it without decoding?
- Precision: If we say data, systems, documentation, or AI, have we named the
  specific work?
- Contribution: Are we using stewardship language and avoiding inflated
  ownership claims?
- Reader burden: Can the value be understood on first pass?

## Preferred Verbs

- built
- co-built
- created
- stewarded
- synthesized
- structured
- translated
- coordinated
- documented
- maintained
- supported
- contributed to
- helped teams use
- made usable

## Use With Care

- under-structured
- lightweight
- tracking
- data
- AI-ready
- source-backed
- Noting.us
- movement librarian
- builds
- maintainers

These words can be accurate, but they often make the reader work too hard. Use
them only when the surrounding sentence explains the artifact, user, or outcome.

## Practical Replacements

Instead of "tracking meetings," use:

> synthesizing meetings, decision records, action items, open questions, and
> follow-up into shared operating memory.

Instead of "lightweight systems," use:

> practical, low-overhead systems people can actually use.

Instead of "data," say whether it means:

- open-data workflows;
- dataset documentation;
- data visualization;
- API requirements;
- data-product requirements;
- source/provenance maps.

Instead of "maintainers," use:

- local calendar organizers;
- community calendar editors;
- project stewards;
- operations owners;
- documentation owners.

## Strong Sentence Shape

Use this pattern when copy gets vague:

> Jamie [accurate verb] [specific artifact/system] for [people/team/context] so
> [useful outcome].

Examples:

- Jamie stewarded campaign-memory infrastructure for Commercial Rent
  Stabilization collaborators so active civic work could remain coherent without
  exposing protected coalition context.
- Jamie co-built WOWList as a community-calendar platform so local arts and
  music organizers could publish, follow, save, sync, and distribute events
  through community vocabulary.
- Jamie built source-backed operating memory practices so teams can preserve
  decisions, open questions, and onboarding context without treating AI drafts as
  authority.
