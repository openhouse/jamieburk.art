# Teams Archive Production Run

**Run date:** 2026-07-14
**Collections appraised:** Jamie Projects History, Commercial Rent Stabilization, and job-hunt working collections
**Operator:** Codex archival review with Jamie Burkart as review owner

## Purpose

Develop the public-safe knowledge bank from Jamie's live working collections
without copying the collections into the public repository. The pass began with
collection overviews and current evidence maps, then close-read selected source
artifacts where they could strengthen an existing claim, create a bounded new
claim, or identify a concrete research path.

## Appraisal Method

1. Start with overview files and current professional-positioning anchors.
2. Compare surfaced material with the existing claim and source registries.
3. Close-read high-signal artifacts rather than recursively ingesting private
   working records.
4. Separate what a source supports from role, causality, ownership, and current
   status that it does not establish.
5. Store protected source metadata and public-safe assertions, never local paths
   or underlying private records.
6. Promote only claims that are mature and useful to the current portfolio
   argument; retain other findings as held knowledge or research tasks.

## Public-Safety Boundary

The repository does not contain working-folder paths, private correspondence,
contact details, raw meeting material, vulnerable business information,
private strategy, legal-review context, pricing, private company context,
participant records, or unapproved media. Protected source IDs preserve
provenance without exposing locators.
