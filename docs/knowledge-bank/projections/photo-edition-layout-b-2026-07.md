# Layout B photographic portfolio edition, July 2026

This is one dated working edition, not the archive's final interpretation.
Every current derivative resolves to a file page and placement matrix. The
East River canary has a verified private binding and bounded creator-permission
summary. Five derivatives still require creator, source, rights, caption, and
production review.

The edition withholds intimate gathering photographs. That absence is
documented as an editorial and consent-aware decision, not treated as missing
product inventory.
