# Projection Guide

Use this when moving material from private memory or collaborator notes into
the public site.

## Intake First

Raw collaborator memory, archival notes, screenshots, private documents, and
draft testimonials should start outside the public repo or in private working
spaces. Do not ask collaborators to open public pull requests with raw proof
material.

## Then Convert

Before a claim appears on the site, convert it into:

- public wording;
- support level;
- evidence class;
- source basis;
- guardrail;
- do-not-say list;
- protected boundaries;
- related project and capability tags.

## Then Project

Only project claims to public pages when they are `ready` or `careful` in
`apps/www/src/data/proofs.ts`.

Use public pages for composed claims. Use docs for governance. Keep raw sources
outside the repo.
