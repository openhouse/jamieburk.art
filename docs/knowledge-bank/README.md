# Knowledge Bank

This directory is the repo-internal, public-safe source of truth for Jamie
Burkart's professional claims. The repository is public, so this bank must stay
safe if copied into a newspaper. It is not an archive dump, CMS, private document
browser, search product, analytics store, or public website section.

The website is a projection of this bank: rhetorically composed for a hiring
reader, optimized for clarity, and limited by privacy, consent, collaborator
trust, and public-safety judgment.

## Files

- `claims.json` is the structured claim register.
- `claims.md` is the human-readable claim matrix.
- `source-classes.md` defines public-safe source classes.
- `approval-register.md` records which surfaces are approved, softened, open, or
  protected.
- `public-safety.md` records publishing boundaries.
- `chad-lens.md` records the editorial lens used to make Jamie legible without
  overclaiming.

## Claim Standard

- **Known:** evidence-backed and public-safe when framed within the listed
  guardrail.
- **Use with care:** usable only with collective-work language, visible limits,
  and review discipline.
- **Softened for production:** a stronger claim exists in the bank, but public
  website copy should use the recommended softer wording unless Jamie explicitly
  approves the stronger surface.
- **Pending approval:** source-backed but not ready for public website use.
- **Protected:** may inform confidence, but should not be published in the site
  or expanded in the public repo.

## Projection Rules

- Use `recommendedPublicWording` by default.
- Use `strongerWordingIfApproved` only on an explicitly approved surface.
- For coalition, civic, public, and community work, prefer collective language:
  helped, co-built, contributed to, supported, stewarded, translated, structured.
- Do not publish raw transcripts, private notes, private correspondence,
  private stakeholder lists, raw community records, internal dashboards,
  legal-review material, client-private artifacts, credentials, or unapproved
  photos.
- The homepage proof strip must use softened public wording for exact metrics
  unless the claim's allowed surface explicitly says otherwise.
