# Knowledge Bank

The knowledge bank is the public-safe source of truth for Jamie Burkart's
professional accomplishment claims.

The website projects from this bank. It should not invent stronger claims in
components, MDX, metadata, or screenshots.

There is intentionally no public `/proofs` page. The bank is repo knowledge for
maintainers and reviewers; the site remains optimized for clarity, audience, and
purpose.

## Files

- `claims.md`: strongest defensible public claims and boundaries
- `sources.md`: public source posture and evidence types
- `projection-map.md`: which claims may appear on which site surfaces
- `publishing-governance.md`: how claims move from evidence to public copy
- `anti-claims.md`: things not to say
- `launch-blockers.md`: what blocks production deploy or indexing

## Principle

Use the strongest accurate claim, not the loudest claim.

Make Jamie visible as an actor without erasing collaborators.

Keep private evidence private. Publish public-safe summaries, aggregate counts,
public links, representative diagrams, and approved artifacts.
