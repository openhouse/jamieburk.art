# Knowledge Bank

This directory is the canonical public-safe knowledge bank for Jamie Burkart's
portfolio.

The website is a projection from this bank. The bank can hold more structure
than the site shows: claim language, approval status, source class, projection
surfaces, protected boundaries, and review ownership. It must not contain the
private source material that helped shape Jamie's confidence.

The repo is public. Do not add anything here that would be unsafe, unfair, too
private, or too hard to defend if quoted in a newspaper.

## Core Rule

Website copy should be strengthened only after the knowledge bank is updated.

Private material may support Jamie's internal confidence, but private material
does not become a public artifact. When a private source supports a public
claim, publish the safest accurate summary and keep the protected source outside
the repo and deploy.

## Files

- `claims.json`: machine-checkable claims, approved wording, projection
  surfaces, approval status, source class, and boundaries.
- `claims.md`: human-readable editorial view of the same claim system.
- `approval-register.md`: what Jamie should approve before production
  publication or indexing.
- `source-classes.md`: what each source class means and what it authorizes.

## Projection Model

- Knowledge bank: public-safe repository layer for defensible claims.
- App projection: `apps/www/src/data/proofs.ts`, the small TypeScript subset
  used by pages.
- Public website: the clearest sequence for the reader and context.
- Private archive: outside this repo.

The site should make Jamie legible as a Technical Project Manager - Product
Operations & Implementation lead who builds operating structure for emerging
public-facing technical work.
