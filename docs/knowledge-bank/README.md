# Knowledge Bank

This is the public-safe source of truth for Jamie Burkart's professional
claims, proof points, source-basis categories, and publication boundaries.

The website is a projection from this bank. It should select the smallest set of
claims that makes Jamie legible to hiring readers, referrers, collaborators, and
public-interest technology teams.

Do not put private source material here. Do not put raw transcripts, private
emails, private coalition notes, legal-review materials, private contact lists,
client-private material, internal analytics, raw community records, unapproved
photos, unapproved quotes, or private/proprietary fonts in this repo.

## Statuses

- `Ready`: strong enough for public site copy.
- `Careful`: usable publicly only with the stated guardrail.
- `Pending`: do not use publicly until approval, citation, or source review is
  resolved.
- `Protected`: source material exists, but the claim or underlying evidence
  should not be published.

## Evidence Classes

- Approved resume.
- Public source.
- Public website / public artifact.
- Public-safe archive summary.
- Firsthand / collaborator context.
- Jamie review confirmation.
- Collaborator approval pending.

## Operating Rule

Every claim should pass the newspaper test: if it would be unsafe, unfair,
embarrassing, or too context-dependent if quoted publicly, it does not belong in
the public repo.

The Knowledge Bank can hold more nuance than the website. The site should show
only the clearest subset for the audience and purpose.
