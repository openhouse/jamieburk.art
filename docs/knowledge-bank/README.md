# Knowledge Bank

This directory governs public-safe professional claims for jamieburk.art.
It is not a private archive, not a transcript store, not a document dump, and not a CMS.

The public website should project from this bank: shorter, clearer, audience-shaped, and careful about consent.

Use this directory to answer five questions before changing public copy:

- What do we know?
- How strongly do we know it?
- Where may we say it?
- What must remain protected?
- What needs Jamie approval before production?

The bank may include public-safe claim summaries, source classes, status, boundaries, approval routing, and projection guidance. It must not include raw transcripts, private coalition notes, legal-review materials, private links, private correspondence, private stakeholder lists, raw community records, internal analytics, credentials, or unapproved photos and quotes.

## Files

- `chad-lens.md`: editorial review lens for professional legibility.
- `publishing-governance.md`: status definitions and publishing rules.
- `claims.md`: compact claim table.
- `public-claims-inventory.md`: where each claim appears.
- `approval-register.md`: items that need Jamie or collaborator approval.
- `source-classes.md`: source categories without exposing sources.
- `projection-guide.md`: how a banked claim becomes site copy.
- `launch-blockers.md`: unresolved production blockers.
