# Knowledge Bank

This is the public-safe knowledge bank for Jamie Burkart's portfolio.

It records the public claims the website may make, the safest wording for each claim, where the claim appears, what kind of source supports it, what still needs approval, and what must remain protected.

This is not a dump of private evidence. Do not commit private emails, raw transcripts, legal-review notes, private coalition materials, private client materials, private analytics, raw community records, unapproved photos, unapproved quotes, credentials, private local paths, or unapproved contact details.

## How The Website Uses This Bank

- `claims.json` is the machine-checkable claim register.
- `claims.md` is the human-readable version for editors.
- `approval-register.md` lists decisions Jamie still needs to approve before production indexing.
- `source-classes.md` defines what kind of support can sit behind a claim.
- `apps/www/src/data/claims.ts` contains the small set of claim IDs currently projected into public homepage proof modules.

The website should select and simplify from this bank. It should not publish the private material that may have helped create internal confidence.

## Rules

- Use approved-public and approved-summary claims in public copy.
- Do not render protected-do-not-publish claims.
- Do not render candidate-needs-approval claims as settled public proof.
- Use helped / supported / contributed to / co-built when work was collective.
- Keep screenshots, quotes, names, metrics, and artifacts out of production until approved.
- Update this bank before strengthening visible website claims.
