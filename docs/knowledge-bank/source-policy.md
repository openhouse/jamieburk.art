# Source Policy

This file is the source-policy entrypoint for the knowledge bank.

The canonical source classes and prohibited source-material rules live in
`docs/knowledge-bank/sources.md`.

Core rule: public claims may be supported by private archives only through
public-safe summaries. Do not commit raw transcripts, private notes, private
emails, private records, private screenshots, credentials, or unapproved
collaborator material to this repo.
