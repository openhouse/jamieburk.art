# Source Policy

The knowledge bank may mention source classes. It must not contain protected
source contents.

Never commit private source files to the repo for the purpose of proving a
claim.

## Source Classes

### public web artifact

Public web pages, public records, public campaign pages, public press, public
GitHub repositories, and materials already intended for public access.

### public resume

Claims present in the current approved resume PDF. Resume contact information
does not automatically become approved HTML content.

### public case-study summary

Public-safe summaries already written for the site or documentation. These may
summarize protected source classes without exposing protected records.

### private source reviewed by Jamie

Source material Jamie has reviewed outside the repo and converted into
public-safe wording. The source itself remains outside the repo.

### private source class only

The source class may be named, but the contents, participants, paths, records,
messages, screenshots, or exact artifacts must not be published.

### sensitive archive - do not commit

Private emails, raw transcripts, private coalition notes, legal-review
materials, stakeholder lists, raw community records, dashboards, analytics,
private client material, private fonts, credentials, and local source bundles.

### third-party approval required

Screenshots, photos, quotes, collaborator names, organizational claims, or other
materials needing approval from someone other than Jamie.

### unverified / do not publish

Claims that are not yet source-backed or that are known to be unsafe for public
release.

## Source Rules

- Link public sources only when the public source supports the claim.
- Use approved resume claims only in the same or narrower wording.
- Use public-safe summaries without exposing protected evidence.
- Keep private source classes outside the repo.
- Do not paste private local file paths into source notes.
- Do not use source material to create new public obligations for collaborators
  who have not approved publication.
