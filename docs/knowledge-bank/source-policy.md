# Source Policy

This file is retained as a compatibility pointer for older knowledge-bank work.

Use `docs/knowledge-bank/sources.md` as the canonical source-class and protected
evidence policy.

The canonical source-class headings are:

- Approved resume
- Approved resume candidate, pending Jamie launch approval
- Public project artifact
- Public website / public artifact
- Public source / public record
- Public-safe archive summary
- Firsthand / collaborator context
- Conversation summary
- Private-source-outside-repo
- Approval pending
- Do-not-publish
