# Source Policy

This file is the concise policy companion to `sources.md`.

## Public Repo

The public repo may contain public-safe source categories, evidence posture,
guardrails, anti-claims, and distilled claims.

## Outside The Repo

Raw source material stays outside the public repo: private correspondence,
transcripts, legal-review materials, private coalition notes, raw community
records, unapproved screenshots, private exports, private spreadsheets,
credentials, and billing records.

## AI-Assisted Review

AI-assisted archival review can support a public-safe archive summary when it is
labeled as review work rather than collaborator testimony. Publish only the
claim, confidence posture, boundary, and public-safe wording.
