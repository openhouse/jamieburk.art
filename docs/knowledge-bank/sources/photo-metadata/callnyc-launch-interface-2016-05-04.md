# CallNYC launch-era public interface capture

The capture records CallNYC's public interface from the Internet Archive's May
4, 2016 replay. It shows the issue-category navigation, resident-facing purpose
statement, Council member profile, service-activity summary, and public
information architecture in one stable frame. The Wayback toolbar was removed
from the portfolio derivative; the captured project interface was not restyled.

The image contains no embedded EXIF, GPS, XMP, private path, or user data. It is
a period-specific product artifact, not current constituent-service guidance.
CallNYC remains an archived independent prototype, not an official New York
City Council service. Historical officeholders, statistics, categories, and
contact information must not be used as current guidance.
