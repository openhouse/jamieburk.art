# KC Town Hall CCED proposal bundle, 2019

## Public-safe source note

The proposal bundle documents an adaptive-reuse project framed around public
benefit, neighborhood participation, first-phase building work, and support
from neighborhood and project partners. A support letter describes Jamie and
Julia as pursuing a listening-driven process rather than treating preliminary
program ideas as a final answer.

The bundle also contains financial, banking, property, professional, and
personal material that must not enter public Git. It does not independently
verify every later field-practice memory, survey response, construction role,
funding outcome, or stewardship transition.
