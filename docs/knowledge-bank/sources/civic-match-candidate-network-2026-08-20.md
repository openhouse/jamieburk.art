# Civic Match candidate network

Work for America describes Civic Match as a nonpartisan talent network that
connects mission-driven professionals with state and local government roles.
The public program page reports more than 12,000 job seekers, more than 1,100
hiring managers, participation across 49 states, and representation from more
than 270 cities as of the retrieval date.

The job-seeker surface offers a discoverable candidate profile, saved roles,
application tracking, employer invitations, staff-assisted matching, and live
events. Hiring managers can search profiles, invite candidates, maintain
shortlists, and use skill tags. These are relationship and intent signals that
a public bulk jobs feed does not provide.

## Authority and limits

The authenticated candidate interface is authoritative for its current field
labels, profile controls, saved state, and invitations. It is not authority for
an external employer's application status or hiring decision. Civic Match's
support documentation says applicants still apply through the employer's
external application path; marking a role as applied records activity within
Civic Match.

The repository retains the public program model, a dated read-only field map,
and a public-safe signup guide. It does not retain passwords, private messages,
account tokens, or protected-category answers. Jamie decides profile
visibility, media consent, relocation preferences, terms acceptance, and final
submission.
