# New York City Council Constituent Services Data Release

The Council described CouncilStat as an application used by district offices
to track constituent issues. It said the data would be updated daily on NYC
Open Data, connected the release to a January 2016 Civic Hall hackathon, and
reported that it was implementing participant suggestions intended to make the
dataset more usable and transparent.

## Boundary

The official page establishes the institutional release and public purpose. It
does not establish that Jamie caused the release, worked for the Council, held
authority over CouncilStat, or developed CallNYC as an official Council
product. It does not say every participant suggestion was implemented.
