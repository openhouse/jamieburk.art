# Campaign-Site Photographic and Media Census

The machine-readable census in
`data/campaign-site-media-census-2026-07-28.json` contains a stable entry for
every distinct recovered work. It covers 531 local references, 355 distinct
local works, and 75 FairRentNYC Flickr photographs: 430 works in all. Visual
review classified 208 photographs and 17 photographic composites as 225 photo
entries.

This census is metadata-only. Prior campaign publication supplies context, not
photographer identity, unrestricted rights, represented-person consent, or a
new portfolio placement decision.
