# Protected communication history - public-safe metadata boundary

This record preserves only the existence and limits of a private source layer.
Raw messages, participant identities, account aliases, relationship graphs,
machine locations, and attachment inventories remain outside this public repo.

The source layer may support a bounded private inquiry into chronology,
corroborators, or prior organizational contact. Any resulting public claim
still requires support, attribution, collective-credit review, consent, and
human approval.
