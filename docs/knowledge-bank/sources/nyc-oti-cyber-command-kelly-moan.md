# NYC OTI - Cyber Command leadership

OTI's official Cyber Command page identifies Kelly Moan as New York City's
Chief Information Security Officer and states that Cyber Command is headed by
the CISO. It does not establish that Moan personally screens Job ID 791074 or
that the role reports directly to her.
