# Jamie Burkart correction to portfolio project-photo credits

Jamie corrected the live portfolio's photo-credit record on August 20, 2026.
When an individual photographer is confirmed, the site may name that person.
When the photographer is not confirmed, the public credit names the project
responsible for the photograph's portfolio use.

This correction preserves internal uncertainty without placing archive-process
language beside a public photograph. It does not infer creator identity,
copyright ownership, depicted-person endorsement, or permission beyond the
already reviewed portfolio occurrence.
