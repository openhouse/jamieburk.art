# Archived NTER CHNG project homepage

The archived homepage credits Drew Bolton, Jamie Burkart, and Garrett Fuselier
and describes a software-and-gallery installation in which public text messages
became a live projected exchange.

It supports shared creator credit and public project description. It does not
divide software, architecture, interaction design, exhibition labor, or later
restaging among the collaborators. It does not establish representative impact
or permission to publish participant messages.
