# KC Town Hall local digital archive review, July 2026

## Public-safe source note

The retained local archive contains a project website and image field, survey
assets, geospatial experiments, and parcel-analysis code and data. One
parcel-distance tool computes distances between building or parcel features and
nearby houses, but its surviving dates and implementation context do not by
themselves establish that it was the earlier citywide site-selection system
described in oral history.

This distinction matters: surviving code can corroborate a practice of
geospatial and parcel analysis without proving that every remembered tool,
workflow, date, or decision survives in the same repository.

## Protection

Exact paths, private images, property records, database contents, survey
responses, source filenames, unpublished contact material, and internal
identifiers remain outside public Git.
