# CallNYC public source repository

The repository preserves the independent prototype's surviving implementation,
including its organization of constituent-services material into a public web
experience.

It supports implementation and interface inspection. It does not by itself
recover every contemporaneous design discussion, establish an official Council
relationship, or prove resident adoption and impact.
