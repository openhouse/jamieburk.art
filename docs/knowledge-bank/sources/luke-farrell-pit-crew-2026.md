# Luke Farrell public professional post - PIT Crew leadership

In a self-authored public post about the launch, Luke Farrell says he is leading
the PIT Crew team. A public Tech:NYC account identifies him as an OTI Deputy
Commissioner. This makes him the nearest publicly identified operational lead
found in the research.

The Senior Product Manager posting does not name a supervisor. This source must
not be converted into a claim that Farrell is the direct hiring manager or will
personally supervise every Senior Product Manager.

See the [public post](https://www.linkedin.com/posts/luke-farrell_today-i-joined-mayor-mamdani-cto-lisa-gelobter-activity-7482497777235808257-cqx4).
