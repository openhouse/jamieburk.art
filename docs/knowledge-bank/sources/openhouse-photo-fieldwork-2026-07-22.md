# openhouse/photo-fieldwork

## What this source documents

The repository defines a local-first workflow for reading and curating an Apple
Photos library without writing to its SQLite database or uploading private
images and metadata to an external service. Its contracts distinguish
retrieval, visual inspection, safety holds, editorial selection, publication
clearance, catalog membership, app receipts, idempotent reruns, and independent
read-only verification.

At the beginning of the July 22, 2026 studio connection, the installed
`curate-apple-photos` skill resolved to this checked-out repository and local
`main` matched `origin/main` at the retrieved revision above.

## Boundary

The public software source documents the workflow, not Jamie's private archive
or the result of any particular selection. It does not establish the contents,
people, places, exact size, rights state, or publication value of the archive.
No private machine profile, library locator, asset identifier, album path,
preview, receipt, or run manifest is reproduced here.
