# Teju Cole - Writers in Residence Zurich profile

The official Writers in Residence profile identifies Teju Cole as the Zurich
resident from June through November 2014. It describes him as a writer, art
historian, and photographer.

This source establishes the residency, location, period, and public
disciplinary description. It does not state what Cole proposed, promise, or
intended to complete there. It does not identify the essay Jamie remembers.
