# NYC Jobs - Cybersecurity Senior Project Manager 791074

The official posting describes a full-time Senior Project Manager in NYC Cyber
Command's Security Sciences unit, using the IT Project Specialist title, at
$75,000-$120,000. It was posted August 14, 2026 and closes October 12, 2026.

The role manages a citywide cybersecurity program portfolio and control
deployments across engineering, operations, and customer applications. It
coordinates legal, contracting, finance, communications, vendors, RFIs/RFPs,
budgets, contractors, risks, cost-benefit work, proof-of-concept/value work,
closeout, documentation, dashboards, reports, and metrics.

The posting prefers six or more years of project management at a large firm or
government entity, Salesforce and ServiceNow, cybersecurity context, and
project-management and cybersecurity certifications. Those are material gaps,
not stated civil-service minima. The posting does not name a direct manager.
