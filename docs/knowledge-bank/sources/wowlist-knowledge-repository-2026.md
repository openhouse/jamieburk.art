# Governed WOW List knowledge repository

This record lets the public-safe Wiki graph acknowledge a private canonical
edition without exposing its URL, clone instructions, protected source
locators, personal data, communications, database rows, or restricted media.

The private repository can support internal observations about facilitation,
onboarding, editorial work, platform maintenance, and source coverage. Public
claims must also stand on public-safe evidence and retain their own boundaries.
The relationship is `private-support`; it is never a rendered public citation.

Repository access is granted case by case. Access is not consent, evidence is
not publication permission, and a private graph relation does not authorize a
public projection. Any outward use requires a separately reviewed candidate
with audience, purpose, selection, collective credit, privacy, rights, consent,
and accountable approval recorded.
