# Campaign-site repository family, 2020-2022

## Public-safe source note

A read-only local Git comparison reproduced a common root history across the
KC Spaces Fund campaign instance and later campaign instances. It also
identified separately versioned reusable theme and fundraiser-display modules.
The reviewed commit subjects describe configurable action buttons, forms,
embeds, typography, colors, fundraising progress, and instance setup.

This establishes literal technical reuse inside a campaign-site family. It
does not establish that the campaigns had the same organizers, governance,
positions, audiences, contributors, communication authors, funding authority,
or outcomes. It also does not establish that the shared implementation caused
fundraising, participation, adoption, or policy change.

The public Wiki does not expose local paths, remote names, server details,
configuration, credentials, private content, or a repository URL. The
protected source remains a research input; its presence does not authorize
publication or access for another collaborator.
