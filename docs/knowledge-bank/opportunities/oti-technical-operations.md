# Opportunity Frame: Technical Operations

Use this page to keep the portfolio aligned with Technical Project Manager,
Product Operations, Implementation, business-analysis, civic-tech, and
public-facing technical operations roles.

## Core Claim

Jamie builds the operating backbone teams need to coordinate delivery, surface
risks early, document decisions, onboard contributors, report clearly, and keep
public-facing technical work moving.

## Proof Pattern

- Emerging work becomes requirements and workflows.
- Stakeholder-heavy work gets decision records and action trackers.
- Public-facing launches get documentation, source maps, onboarding, and
  durable handoffs.
- Private evidence remains protected.

## Best Public Examples

- Harry J. Epstein Company: legacy operations, e-commerce, analytics, content,
  workflow, and handoff systems.
- FairRentNYC / CRS: campaign-memory infrastructure, action trackers, source
  maps, decision records, and collective-work boundaries.
- CallNYC: civic open data translated into resident-facing guidance.
- 196 / Sunday Dinner: participation infrastructure, onboarding, facilitation,
  and continuity.
- Source-Backed Team Memory: reviewable AI-assisted documentation with human
  acceptance and privacy boundaries.

## Avoid

- Employer-specific tailoring.
- Unsupported ownership claims.
- Dense source-led metrics on first read.
- Tool lists that make the operating contribution disappear.
