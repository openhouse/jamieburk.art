# NYC OTI Technical Operations Manager

The official posting describes ownership of a small public-interest technology
team's operating backbone: hiring, planning, delivery tracking, onboarding,
leadership reporting, decisions, runbooks, risk, dependencies, and continuous
improvement. Jamie's public portfolio is strongest on operating documentation,
ambiguous-to-usable delivery, and public-facing systems.

The main open question is not whether the vocabulary matches. It is whether the
application and interview can show concrete authority, scale, procurement
experience, and operating metrics without overstating collective projects.

This record contains no private application status or warm-path notes. Reverify
the [official posting](https://cityjobs.nyc.gov/job/technical-operations-manager-in-brooklyn-jid-44321)
before using it as a live target.
