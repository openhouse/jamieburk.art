# Source-Backed Team Memory

This is internal opportunity context. The public page should remain bounded as a
lab / proof-of-practice.

## Practical Frame

I do not hear this as a need for more notes. I hear it as a need for operating
memory.

## Core Offer

A bounded, source-backed memory sprint for a fast-growing creative technical
team.

## What It Creates

- decision records;
- open questions;
- onboarding context;
- source-linked notes;
- human-reviewed AI-assisted documentation;
- privacy, access, and retention notes.

## Boundary

Not production SaaS.
Not an omniscient AI layer.
Not a private archive browser.
Not broad ingestion.
Not a replacement for human judgment.
Do not name private collaborators, client details, pricing, or unapproved
examples.

## Core Line

AI drafts. Humans review. Sources remain inspectable. Corrections remain possible. Private material stays private.

## Public-Site Boundary

Do not publish Jonathan-specific private material. Use the opportunity frame to
preserve context internally while the public lab page stays general, bounded,
and human-reviewed.
