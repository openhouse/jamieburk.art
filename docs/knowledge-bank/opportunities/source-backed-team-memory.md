# Opportunity Frame: Source-Backed Team Memory

Source-Backed Team Memory is a bounded early method / consulting practice. It
should support conversations about source-grounded documentation, AI-assisted
synthesis, decision memory, and team onboarding without overtaking the homepage
identity.

## Public-Safe Frame

AI drafts. Humans review. The shared record remains inspectable and correctable.

## Outputs

- useful ideas;
- decision records;
- open questions;
- onboarding context;
- source-linked notes;
- owners;
- next steps;
- current status;
- human review;
- trust / privacy checks;
- accepted team memory.

## Boundaries

It is not finished production SaaS. It is not an AI replacement for judgment. It
is not a private archive browser. It should not request broad company-system
access as a public-site promise.

## Role Fit

This supports Technical Operations by showing Jamie's ability to preserve
decisions, expose uncertainty, maintain source trails, and help teams re-enter
complex work without pretending that automation removes human responsibility.
