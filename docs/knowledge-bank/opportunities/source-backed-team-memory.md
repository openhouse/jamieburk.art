# Opportunity Lens - Source-Backed Team Memory

This file maps public-safe claims to AI-assisted, human-reviewed team memory and
consulting conversations.

## Public-Safe Core

A bounded lab method for source-backed team memory: reviewable,
human-correctable, source-linked operating memory for knowledge-heavy teams.

AI drafts. Humans review. The shared record remains inspectable and correctable.

A protected two-page proposal authored by Jamie on June 26, 2026, establishes
the method beneath this public summary. It defines a bounded loop from approved
source to structured record, source-linked draft, ideas/decisions/open
questions, trust and privacy check, accepted team memory, and human correction.

Operating memory helps a team understand what has been decided, why it was
decided, what source material supports that understanding, what remains open,
who holds which context, and what new collaborators need in order to join
intelligently.

## Public-Safe Deliverables

- knowledge-friction map;
- source / workflow inventory;
- decision-memory template;
- meeting-memory template;
- onboarding or "how we know what we know" starter page;
- privacy, access, and retention notes;
- 30-day continue / revise / stop recommendation.

The proposal limits the sprint to one approved non-sensitive or synthetic
source and one narrow use case. That boundary is part of the method, not a
temporary omission.
