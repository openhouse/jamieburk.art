# Source-Backed Team Memory

Source-Backed Team Memory is a method for turning fragmented project records
into governed, usable knowledge. It separates what is known, attributed,
inferred, unresolved, protected, and selected for a particular audience.

This page describes the method rather than claiming that every archive is
complete or every source is public. The broader
[lifecycle](../lifecycle.md) governs capture, research, promotion, projection,
correction, and retirement.
