# Correction Policy

Corrections make the editorial history traceable without making public pages
feel like correction ledgers.

When a public claim changes because the evidence has been clarified:

1. Correct the public copy.
2. Add or update the supporting claim and citation notes.
3. Record the correction in `apps/www/src/data/citations/corrections.json`.
4. Link the correction to the claim records that support the corrected wording.
5. Decide whether a public note is required.

## Current CallNYC Corrections

- CallNYC period: corrected from `2014-2015` to `2016`.
- Hackathon description: corrected from broad first-hackathon language to
  `first CouncilStat hackathon`.

The public CallNYC page does not need a correction notice because the earlier
phrasing had not been established as a public promise to readers. The correction
record preserves the editorial history for future maintainers.
