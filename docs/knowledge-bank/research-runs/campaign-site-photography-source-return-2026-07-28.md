# Campaign-site photography source return, July 28, 2026

## Encounter

This pass looked first at the public pages as composed historical surfaces.
It then used only the public image filename or Flickr identifier to query the
private local inventory. That order matters: the page supplies a situated
question before the archive supplies possible relatives.

The declared public field contains 82 pages, 529 image occurrences, 413 unique
image URLs, and 181 photo or portrait entries. Twenty-nine entries returned 57
local candidate assets. No private identifiers, People data, coordinates,
archive paths, or image pixels entered the repository.

## Present reading

The sites already embody years of photo editing. Their images are not a neutral
pool. They show what the campaigns believed would make testimony, gathering,
place, pressure, and collective presence legible. The Wiki now preserves that
prior edit as context while refusing to treat it as automatic permission for a
new portfolio composition.

## Next source return

The next high-value pass is human and selective: choose a small number of
campaign images, retrieve their candidate originals and nearby temporal
families locally, inspect them visually, and invite oral history. Only after
that return should an image receive an exact caption, creator credit, crop,
destination, and production decision.

## Publication boundary

All generated records remain metadata-only and on display hold. This research
run authorizes no new public image occurrence.
