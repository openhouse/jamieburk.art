# NYC Artist Coalition shared-folder archival production

## Question

What can complete, governed accounting of the accessible NYC Artist Coalition
shared folder clarify about Jamie's professional role, coalition practice, and
application story without publishing private collaborative records?

## Method

1. Open the shared folder through Jamie's authenticated browser session.
2. Reconcile the 61 root items, including 47 folders and 14 files.
3. Recursively open every accessible folder discovered through the interface.
4. Record every item in a private manifest with an exact identifier, private
   path, source metadata, and exactly one primary disposition.
5. Select priority documents by mission relevance and role-attribution value,
   while excluding contact, participant, credential, billing, and other
   sensitive records from content promotion.
6. Close-read 63 private text exports across eight semantic clusters.
7. Promote only public-safe propositions with claims, anti-claims, credit
   scope, source relationships, projection status, and open inquiries.
8. Run population, disposition, leakage, graph-closure, collective-credit, and
   selective-projection checks.

The private source set contains 351,532 reviewed characters. The public report
does not contain those characters, raw excerpts, or private locators.

## Findings

The close reading promoted four findings: a shared advocacy operating guide, a
bounded Office of Nightlife town-hall role, task-level Fair Rent web
implementation, and a recurring participatory-governance pattern. These
strengthen existing public-source claims; they do not replace public
corroboration for events, laws, institutional action, or outcomes.

## Dispositions

Every item has one primary disposition. Most visual and production assets
remain in rights review. Many additional documents remain deferred or protected
instead of being described as reviewed. The public-safe disposition totals are
stored in the [aggregate census](../data/nycac-shared-folder-census-2026-07-19.json).

## Human gates

- Jamie review of promoted language remains open.
- Collaborator review is needed before using finer attribution or quotations.
- Rights and represented-person review remain open for visual and media assets.
- Application selection remains audience-specific.
- Production approval remains separate from passing automated checks.
