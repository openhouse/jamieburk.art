# Projection Map

The website is a composed projection of the knowledge bank. The bank holds
structured, public-safe claim discipline. The site chooses the clearest public
sentence for each audience and surface.

This is not a `/proofs` page. It is a publishing map.

## Projection Rules

- Project claims only from `claims.json` or an explicitly reviewed public page
  source.
- Use `recommendedPublicWording` by default.
- Use `strongerWordingIfApproved` only where the approval register allows that
  surface.
- If a claim depends on collective work, name Jamie's role without erasing the
  collective.
- If a claim depends on private archive review, publish only the approved
  public-safe summary.
- If a claim would require raw proof to be convincing, keep it out of public
  pages until a safe public artifact exists.
