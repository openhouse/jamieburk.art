# Visual Evidence Register

This register records the public-safe professional findings from a July 2026
whole-library photo review. It stores conclusions and boundaries, not images,
private album inventories, face data, exact locations, or private captions.

The review used local pixel inspection, existing archive provenance, five
recursive evaluation rounds, and a separate safety HOLD. Its final editor field
contained 4,000 unique photographs. This is source discovery, not a final
publication edit.

## Governing Rule

A photograph can support visible context: a person, place, room, artifact,
public action, or material trace. It cannot by itself prove authorship,
causality, sole leadership, an exact metric, participant consent, caption
accuracy, copyright ownership, or permission to publish.

## Cross-Cutting Discovery

The archive gives Jamie's operating practice a concrete visual vocabulary:

- people using working rooms rather than posing for generic collaboration;
- storefronts, campaign signs, public meetings, and civic actions;
- screens, documents, tools, and production equipment;
- tables, food, storage, lighting, and other hospitality infrastructure;
- buildings, thresholds, and traces of long-term stewardship.

This pattern supports the idea that Jamie's work joins people, environments,
artifacts, and repeatable operating structure. It is contextual support, not a
replacement for project records or collaborator testimony.

## Safety Discoveries

The review repeatedly found material that may be archivally meaningful but is
not automatically public-safe:

- handwritten names, lists, notes, and private-message imagery;
- identifiable people in private hospitality or domestic settings;
- family and personal photographs;
- private participant context that a visible scene cannot explain;
- images whose metadata suggests a project but whose pixels do not.

These belong in protected review until image-specific consent, caption,
attribution, and rights questions are resolved. Access is not consent.

## Retrieval Lessons

- A prior editor album can create a feedback loop and must not become its own
  evidence.
- A face near a table is not proof of work.
- A machine label is not proof of Technical Operations.
- Generic `people` and `adult` labels are not proof of hospitality.
- Project adjacency is not project provenance.
- Sparse, defensible evidence is better than a large mislabeled category.
- `Unclassified / Editor Field` is a productive category, not a failure.

## Publication Gate

Before any photograph reaches the website, record:

- the page and editorial function;
- a verified public-safe caption;
- photographer and rights status;
- participant and collaborator consent where needed;
- credit language;
- crop and accessibility review;
- whether the image supports orientation, proof, human stakes, or more than one;
- the claim ID it supports, if any;
- what the image must not be used to imply.

Until that review is complete, visual evidence remains knowledge-bank context,
not a public website asset.
