# Visual Proof Plan

The first visual pass should demonstrate work, not decorate claims. Priority
sequences are: a real system in use; the operating artifact behind it; the
people, place, or public context affected; and a caption that states what the
image can and cannot prove.

Every selected visual needs:

- project, date or bounded period, and source location;
- creator and rights or consent posture;
- public/private classification;
- the claim it supports;
- a factual caption and collective credit;
- an explicit approval decision before website projection.

The current approved count is intentionally zero. The site labels its current
cards as artifact descriptions, not an image gallery. Candidate discovery can
proceed without implying approval.
