# Citation Policy

## Purpose

Citational care reduces the reader's burden while preserving the limits of the
record. Public pages cite precise claims. The Knowledge Bank records how sources
support, qualify, limit, contradict, or fail to resolve those claims.

## Public Projection

- Write a clear proposition before adding a citation.
- Attach the marker to the smallest factual clause the evidence supports.
- Use claim-level page-local numbering; never store numbers in canonical data.
- Repeated uses of one claim reuse one number and receive unique occurrence IDs.
- One note may group several sources supporting the same claim.
- Public prose must remain useful when a reader ignores every note.

## Source Boundaries

- Prefer durable archived URLs for fragile public sources.
- Offer the original URL second when both are safe and useful.
- Protected and private sources render safe citation text without a URL.
- Never commit local paths, private filenames, identity metadata, signed URLs,
  credentials, raw correspondence, or unapproved artifacts.
- A source cannot establish what its own boundary note says it does not
  establish.

## Epistemic Change

- Record corrections rather than silently forgetting superseded wording.
- Superseded claims cannot project publicly.
- `responsible_inference` requires an explicit qualifier.
- `not_recovered` requires the search method, scope, and limitation.
- A negative search result describes the searched corpus; it does not prove
  nonexistence.

## Assets And Rights

Assets record provenance separately from source citations. Public use requires
cleared rights and cleared or unnecessary consent. Metadata-only and withheld
assets do not render. The CallNYC participant photograph remains protected and
metadata-only pending rights, consent, caption, and crop review.

## Review

Run the citation validator, regression tests, deterministic report, repository
checks, public-safety checks, and visual/keyboard QA before review. Corrections
marked required before production remain launch blockers until resolved.
