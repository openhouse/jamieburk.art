# Professor Lens Evals

These two lenses recover dimensions of Jamie's practice that a hiring-only
evaluation system can flatten. They are AI-authored editorial controls grounded
in protected historical evidence and tested against public-safe proof already in
the portfolio system.

**Historical evidence is not present-tense endorsement.** Neither lens is
written by the named professor, reports a professor's current opinion, or
records a current professor review. The underlying unofficial evaluation copy,
private correspondence, student data, private locators, and protected screenshot
remain outside this public repository.

Automated protocol readiness is not a human result. Each lens retains a separate
manual gate that an independent editor must run from the current public site
without seeing the private professor materials.

## Margaret Morse lens preserves embodied and artistic intelligence

Manual gate: `embodied-practice-editorial-review`

This lens asks whether the portfolio can recognize value that is not exhausted
by organizational utility: experimentation, hospitality, atmosphere, artistic
investigation, embodiment, attention, and relationships. It looks for systems
concerned with participation, memory, place, and how people inhabit structures.

The gate passes at the protocol level only when:

1. Existing public sources preserve creative-technology and participatory work
   as evidence, even when that work remains reserve depth.
2. The current public hiring path still names human stakes, cultural
   infrastructure, public-facing tools, usable interfaces, and collective care.
3. At least one evidentiary threshold ensures that artistic, civic, technical,
   and social practices remain connected across the public site and knowledge
   bank.
4. Historical praise, grades, evaluation text, private correspondence, and
   protected screenshots remain outside public copy.
5. An independent editor, not an authoring agent, determines whether the live
   composition preserves these dimensions without obscuring role fit.

Anti-gaming rule: do not make artistic work legible only by translating it into
productivity, scale, or professional utility. Do not auto-publish professor
material, invent present endorsement, or treat historical course work as proof
of current proficiency. Do not flatten unlike projects into a single seamless
practice.

Stop when the public hiring argument is clear, the knowledge bank retains the
harder-to-hire dimensions of the practice, and the independent review question
is explicit. The automated system must not answer that human question for
itself.

## Warren Sack lens preserves recursive technical-social systems thinking

Manual gate: `recursive-social-systems-editorial-review`

This lens asks whether technical work is legible as more than a technology list
or engagement count. It looks for a recurring movement from social structure and
recursive relation modeling to a working prototype and interface, physical and
digital interaction, multimodal documentation, collective authorship and
dialogue, and a system other people can inhabit or continue.

The gate passes at the protocol level only when:

1. A reviewer can trace at least one relationship model, implementation,
   interface or embodied interaction, and documentation system.
2. Public proof connects software and operations to the people, relationships,
   and institutional context the system organizes.
3. Group work remains group work: co-design, collaborators, and dialogue stay
   inside the technical account.
4. Mutable engagement totals remain signals rather than substitutes for
   interaction design, stakeholder response, adoption, or impact.
5. Protected historical observations remain historical context rather than
   claims of current technical authority.

Anti-gaming rule: do not satisfy this lens with technology names, archive
volume, or social metrics alone. Do not promote the protected historical
structural-equivalence observation into public credential copy, infer current
skills from old course work, or erase the jointly designed installation from
its group context.

Stop when relation, implementation, interface, documentation, use, and
collective credit travel together through current public proof. The independent
editorial review remains required.

## Recursive Protocol

1. Run `npm run evals:launch` and retain the baseline.
2. Repair failed source, privacy, evidence, projection, or anti-gaming checks.
3. Run the focused adversarial tests.
4. Run the full repository check.
5. Keep both human results at `required-not-run` until independent reviewers
   produce new evidence from the public site.
