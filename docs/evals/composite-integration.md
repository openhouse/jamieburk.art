## Deliberately not imported

- Competing Knowledge Bank schemas and lifecycle registries.
- Duplicate versions of domain evals already stronger in B.
- Large generated run corpora unrelated to the selected candidate.
- Claims, metrics, or public copy absent from the B canonical bank.
- External network calls in required CI.
- Automated human approvals.
- Production deployment or indexing state.
- Branch-specific resume generators that are not the approved current workflow.

## Authority

Deterministic scripts certify machine-observable facts. LLM judges provide
bounded editorial judgment. Humans own shareability, corroboration, rights,
interpretation, and release. External outcomes remain observations.

The composite can be system-ready while application-ready or production-ready
is human-blocked. This is an honest state, not a test failure.
