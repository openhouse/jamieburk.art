# `feature/knowledge-f`

## Intent

Integrate the strongest compatible ideas from the frozen `feature/evals-A` through `feature/evals-N` family into one canonical knowledge and launch-evaluation system. The branch starts from the current F spine and targets `develop`.

## What Changed

- added a versioned composite contract that freezes 52 criteria across eighteen evaluation families;
- bound reports to the exact Git candidate, worktree state, contract, material inputs, evaluator implementation, and public citation registry;
- added canonical knowledge-graph closure across intake, projects, sources, claims, inquiries, corrections, page occurrences, publication decisions, and proof coverage;
- added selective-projection validation so reserve, hold, retired, protected, private-support, and rights-pending evidence cannot silently enter public routes;
- added normalized public-safety inspection for encoded, escaped, Unicode-obscured, and aliased private values;
- added adversarial evaluator-integrity tests and a clean-candidate two-pass certification command;
- documented A-N adoption decisions, the recursive hill climb, and every remaining human boundary;
- preserved the approved integration brief as `instructions-f.md`.

## Composite Decisions

The implementation retains F's evaluator, knowledge-bank schema, public citation registry, release gates, and manual approvals. It adopts provenance closure from A, separated governance from B, candidate fingerprints from C and G, versioned contracts from D, typed lifecycle semantics from E, close-reading restraint from H, evaluator-correctness mutations from I, optimizer/judge separation from J, operational integrity from K, compact preflight discipline from L, selective composition from M, and normalized cross-surface safety from N.

Parallel branch-letter schemas, runners, historical rubric directories, and duplicate report formats were deliberately omitted.

## Hill-Climb Result

The inherited baseline passed 138 eval tests and 47 launch criteria at 100/100. The first composite run failed at 99/100 because the new contract required a certification command that was not yet wired. After implementation, a full check exposed secret-shaped synthetic fixture literals; those fixtures now assemble only at runtime.

The final precommit state passes 155 eval tests and all 52 launch criteria at 100/100. The clean pushed candidate is certified twice after commit; its exact SHA and fingerprints belong in the live PR record because a tracked file cannot embed the hash of its own containing commit.

## Public Safety And Projection

No private archive, source path, raw transcript, correspondence, stakeholder identity, credential, unapproved image, or protected locator was added. The public citation registry and public-facing portfolio projection are unchanged. The integration improves how future evidence is governed without converting knowledge depth into public-site volume.

## Human Gates
