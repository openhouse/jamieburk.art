# Public Claim Review

This note tracks public-safe claims used in the portfolio copy. It records only
aggregate or summary-level evidence. Raw archives, private notes, contact data,
private correspondence, legal-review context, credentials, and unapproved media
stay out of the repo and public site.

## Claim Tiers

- Known: public-safe and evidence-backed enough to use in portfolio copy.
- Open: needs exact citation, screenshot approval, collaborator approval, or
  stronger source review before publication.
- Protected: intentionally omitted because privacy, consent, client trust, law,
  civic sensitivity, or community safety requires it.
