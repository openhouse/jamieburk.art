# Public Claim Register

This register translates private archive review into public-safe claim language.
It is for portfolio maintenance, not for publishing raw source material.

Use the same model as the case-study pages:

- Known: public sources, approved resume language, or aggregate source-backed
  summaries that can appear publicly.
- Open: claims that need Jamie, collaborator, screenshot, citation, or wording
  approval before launch.
- Protected: source material and details that stay outside the repo and off the
  public site.

## Global Rules

- Put Jamie in the sentence when the claim is about Jamie's work.
- Explain the purpose of the work, not just the artifact.
- Avoid reader-decoding burden: define acronyms and spell out uncommon terms.
- Use collective-work language when the record is collaborative.
- Use precise counts only when the count is sourced and the scope is named.
- When uncertain, write `TODO: Jamie approval required.`
