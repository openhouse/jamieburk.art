## Proposed Bounded Loop

Hi Jonathan,

I would like to propose a small source-backed team memory pilot rather than a
large abstract AI project.

The simplest useful loop would be:

1. 45-minute working session.
2. One safe use case.
3. One non-sensitive or synthetic source bundle.
4. Small prototype or recommendation memo.
5. Next-phase decision.

The public-facing version of the practice is here:

https://jamieburk.art/lab/source-backed-team-memory

The principle is simple: AI drafts. Humans review. The shared record remains
inspectable and correctable.

Best,

Jamie
