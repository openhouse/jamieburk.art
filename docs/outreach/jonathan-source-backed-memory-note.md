## Short Note

I have been shaping Source-Backed Team Memory as a bounded lab / method for
knowledge-heavy teams. The idea is a small, human-reviewed loop for preserving
meeting memory, decision rationale, source links, unresolved questions, and
onboarding context without turning documentation into a heavy process or a
private archive browser.

Relevant pages:

- https://jamieburk.art/lab/source-backed-team-memory
- https://jamieburk.art/work/technical-operations

Boundaries:

- Not production SaaS.
- Not a chatbot over private archives.
- Not an AI replacement for judgment.
- Humans remain the authority.
