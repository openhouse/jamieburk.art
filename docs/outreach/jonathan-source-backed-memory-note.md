# Jonathan / Source-Backed Team Memory Outreach Note

Hi Jonathan,

I have been thinking about the knowledge-management problem you described: a
small, fast-growing team where decisions, rationale, onboarding context,
unresolved questions, and useful ideas can fall through the cracks across
meetings, documents, chat, and AI summaries.

I would be excited to explore a small source-backed team memory pilot with you.
A practical first scope could be:

1. Decision-memory audit - where decisions, open questions, and rationale
   currently get lost.
2. Source-backed synthesis workflow - a repeatable pattern for turning meetings
   and source material into decisions, open questions, follow-ups, and
   onboarding-ready context.
3. Human-reviewed operating memory - summaries tied to source material,
   uncertainty, and review so the team can trust and correct the record.

The principle is: AI drafts. Humans review. Sources remain inspectable.
Corrections remain possible. Private material stays private.

Warmly,
Jamie
