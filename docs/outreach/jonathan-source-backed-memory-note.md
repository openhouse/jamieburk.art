# Source-Backed Team Memory Outreach Note

Public-safe working copy for a bounded source-backed memory conversation.

## Short Note

Hello,

I have been shaping Source-Backed Team Memory as a practical method for helping
knowledge-heavy teams preserve useful decisions, source context, onboarding
knowledge, and open questions without creating a heavy parallel bureaucracy.

The method begins with one bounded use case and one approved source bundle. AI
can draft summaries or proposed memory entries, but humans review. The shared
record remains inspectable, correctable, and tied back to sources. Privacy,
access, retention, IP, confidentiality, and compensation boundaries are part of
the work from the beginning.

The public lab page is here:
https://jamieburk.art/lab/source-backed-team-memory

I would be glad to discuss whether there is one contained pilot where useful
ideas, decisions, and context are being lost on the cutting-room floor and could
be preserved safely.

Jamie

## Guardrails

- one bounded use case;
- one approved source bundle;
- human review remains central;
- records remain inspectable and correctable;
- access, retention, IP, privacy, and confidentiality are explicit;
- not a broad archive browser;
- not a finished SaaS claim;
- not AI replacing judgment.
