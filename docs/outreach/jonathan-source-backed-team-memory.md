# Jonathan / Source-Backed Team Memory Note

The small project I would propose is a Source-Backed Team Memory Sprint: a
bounded 1-2 week engagement to help a fast-moving team preserve decisions,
source context, open questions, and onboarding knowledge without creating a
heavy knowledge-management system.

The goal is not "more notes." The goal is to prevent valuable ideas from being
left on the cutting-room floor and to make team memory inspectable, correctable,
and useful.
