# Typefaces

The shipped web typefaces are Karla and Archivo Narrow, both loaded through
`next/font/google`.

- Karla: body, UI, prose, navigation, and long reading.
- Archivo Narrow: display headings, eyebrows, proof labels, status badges, and
  compact public-grotesque emphasis.

Do not commit or serve private or proprietary font files. Trade Gothic, Verlag,
and Gotham Rounded are not shipped unless Jamie confirms licensing. The Maria
handwriting font is not shipped unless Jamie explicitly confirms permission.

No `.ttf`, `.otf`, `.woff`, or `.woff2` files should be added to the repo without
explicit approval.
