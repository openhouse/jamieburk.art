# Typefaces

The V1 site uses Google-hosted fonts through `next/font/google`.

- Karla carries readable prose and interface text.
- Archivo Narrow carries compact headings, proof labels, metadata, and
  civic-notice moments.

No private or proprietary font files are committed or served.

## Rules

- Do not commit `.ttf`, `.otf`, `.woff`, or `.woff2` files without explicit
  approval.
- Do not reference private or proprietary fonts in public-facing source.
- Keep letter spacing at `0`.
- Use Archivo Narrow sparingly; do not use it for long body copy.
