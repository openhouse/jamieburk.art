# Typefaces

V1 uses safe web fonts through `next/font/google`.

## Shipped Fonts

- Karla for body text, UI, prose, navigation, buttons, and long-form case-study reading.
- Archivo Narrow for display headings, proof labels, eyebrows, and compact metadata.

## Not Shipped

- Do not commit, serve, or reference private or proprietary font files.
- Do not ship Trade Gothic, Verlag, Gotham Rounded, the Maria handwriting font, or other private/commercial fonts unless Jamie provides explicit licensing/permission and asks for a later change.
- The Maria handwriting font is consent-bound and must not enter the public repo.

No `.ttf`, `.otf`, `.woff`, or `.woff2` file belongs in this repo for V1.
