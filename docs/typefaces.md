# Typeface Policy

V1 uses safe web fonts served through the existing Next.js font configuration.

Current public stack:

- Karla for body and UI text.
- League Spartan for display headings.

Only open, safe web fonts are served. Trade Gothic, Verlag, Gotham Rounded, FondFont RISQUÉ, and Maria's handwriting font are design references only and are not committed or served unless explicit licenses / permissions are supplied.

Do not commit `.ttf`, `.otf`, `.woff`, or `.woff2` files to this repo for V1.
