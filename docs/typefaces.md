# Typefaces

V1 serves only public web fonts through `next/font/google`:

- Karla: body, prose, UI, case-study text.
- Archivo Narrow: display headings, labels, eyebrows, proof labels, and compact
  public-notice moments.

Do not commit or serve private/proprietary font files:

- Trade Gothic
- Verlag
- Gotham Rounded
- Risque
- Maria handwriting font
- `.ttf`, `.otf`, `.woff`, or `.woff2` files without explicit licensing approval

Design references may remain references. They are not production assets.
