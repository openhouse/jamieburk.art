# Typeface Policy

V1 ships safe web fonts only.

## Shipped

- Karla: body/UI/prose.
- Archivo Narrow: display headings, eyebrows, proof labels, compact public-grotesque emphasis.

## Reference only unless licensed

- Trade Gothic Bold
- Verlag Black
- Gotham Rounded
- Risque, if license still needs review

## Private / Permissioned Only

- Maria handwriting font

## Rules

- Do not commit private or proprietary font files.
- Use `next/font/google` for shipped Google Fonts.
- Do not add `.ttf`, `.otf`, `.woff`, or `.woff2` files without explicit approval.
