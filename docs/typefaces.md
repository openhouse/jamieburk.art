# Typeface Policy

V1 public web font: Karla.

Do not commit Trade Gothic, Verlag, Gotham Rounded, FondFont RISQUE, Maria handwriting font, or any private/proprietary font files.

Approved open role-equivalent fonts if needed later:

- Archivo Narrow for condensed civic headline role.
- League Spartan for geometric all-caps threshold role.
- Nunito for rounded UI role.
- Rubik Dirt for rough handmade artifact role.
- Caveat for handwritten annotation role.

Do not call any substitute font "Maria." Do not imply it reproduces Maria Schoettler's handwriting.
