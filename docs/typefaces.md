# Typefaces

The shipped type system is:

- Karla for body/UI/prose.
- Archivo Narrow for display headings, eyebrows, proof labels, and compact
  public-grotesque emphasis.

Both faces are loaded through `next/font/google` in `apps/www`.

## Policy

- Do not commit or serve private or proprietary font files.
- Do not add `.ttf`, `.otf`, `.woff`, or `.woff2` files unless Jamie explicitly
  confirms licensing and permission.
- Trade Gothic, Verlag, and Gotham Rounded are not shipped unless properly
  licensed.
- The Maria handwriting font is not shipped unless explicitly permissioned.

## Use

Keep Karla as the default reading voice. Use Archivo Narrow sparingly for
headings, status labels, proof numbers, and compact metadata. The site should
remain calm and readable, not poster-like.
