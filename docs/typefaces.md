# Typeface Policy

## Shipped

- Karla: body, UI, and prose.
- Archivo Narrow: display headings, eyebrows, proof labels, metadata labels, and selected emphasis.

## Not Shipped Unless Licensed

- Trade Gothic Bold.
- Verlag Black.
- Gotham Rounded.
- Risque / RISQUE.

## Not Shipped Unless Explicitly Permissioned

- Maria handwriting font.

## Rules

- Do not commit private or proprietary font files.
- Do not reference proprietary font names in shipped CSS stacks.
- Use `next/font/google` for V1.
- Document any future typeface change before shipping it.
