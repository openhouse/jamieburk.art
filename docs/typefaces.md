# Typeface Policy

The V1 site uses safe web fonts loaded through `next/font/google`.

- Karla: body text, UI text, cards, and long-form prose.
- Archivo Narrow: display headings, section eyebrows, proof labels, compact
  metadata, and selected emphasis.

Do not commit or serve private, proprietary, or unlicensed font files. In
particular, do not add Trade Gothic, Verlag, Gotham Rounded, RISQUE, Maria, or
local `.ttf`, `.otf`, `.woff`, or `.woff2` files without explicit license and
publication approval.

Generated Next font files under `.next` are build artifacts and should remain
ignored.
