# Typefaces

The shipped V1 type system is:

- Karla: body text, UI text, navigation, buttons, prose, and dense explanatory copy.
- Archivo Narrow: display headings, section eyebrows, proof labels, metadata labels, and selected emphasis.

Use `next/font/google`. Do not commit font files.

Private, proprietary, or unlicensed fonts must not be committed, bundled, or
served from the site. Historical design references may be discussed in private
notes, but shipped CSS stacks should stay with the approved public web fonts and
system fallbacks.
