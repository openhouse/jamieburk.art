# Layout E: Photography Integration

Date: 2026-07-22

## Intent

This branch moves photography from a future possibility into the actual portfolio composition. The image layer is not decoration and it is not a second proof bank. It is a situated record of people, places, materials, scale, and the conditions in which the work happened.

The layout gives photographs enough space to establish a world before asking a stranger to interpret a claim. Type, captions, links, and evidence then help the reader move through that world without forcing every image to behave like a metric.

## Visual System

The design uses the Human Index material palette:

- work-jacket blue for primary action and continuity;
- institutional green for stewardship and quieter supporting structures;
- red-pencil accent for correction, attribution, and accountable intervention;
- graphite for machinery, formal navigation, and high-contrast reading bands;
- corroboration green and dispute ochre where knowledge status is relevant.

Paper white remains the reference reading surface. Rules, ledger rows, and restrained index labels replace most decorative cards. The system uses no gradient decoration. Photographs carry depth and atmosphere.

## Caption Contract

Each selected archive image has:

- a stable public identifier;
- descriptive alt text that does not duplicate the caption;
- a short contextual caption;
- project-level or author credit;
- an explicit context category;
- a stable crop position where the default center would weaken the scene.

Captions must not convert proximity into sole authorship. Collective campaigns remain collective. Jamie's contribution is described as operational, technical, artistic, organizing, or documentary work only where the current record supports that framing.

## Public Derivatives

The branch contains nine selected JPEG preview derivatives. Embedded archive metadata and private library coordinates are not carried into the public assets. Source-library identifiers, private filesystem paths, and held-sensitive images do not enter application code, captions, or this record.

Jamie authorized these derivatives for public pull-request review as part of this actual layout experiment on July 22, 2026. That authorization names this working branch and review surface. Production approval remains an open human decision, including final rights, exact credit, crop, and represented-person dignity review. Passing an automated check is not publication clearance.

Two small-space gathering images in the initial edit, one from Sunday Dinner and one from an NYC Artist Coalition monthly meeting, were held back and removed from the public branch after independent review found no asset-specific represented-person approval record. The omission is intentional. Those images may return only through a later, recorded human decision.

The raft now carries its collective-role caption immediately beneath the hero. The image therefore cannot quietly recast Jamie as captain: it identifies his work as tending a sound, stable, shared experience inside a multi-person project.

## Evaluation Loop

The layout is evaluated in four complementary ways:

1. Static checks verify asset integrity, complete caption records, public/private boundaries, stable image geometry, collective-credit language, the Human Index palette, and the retained hiring path.
2. Node tests ensure every committed photograph is represented in the typed manifest and the evaluator itself reaches its blocking threshold.
3. Type, lint, build, route, public-safety, and existing Knowledge Wiki checks catch integration regressions.
4. Browser screenshots at desktop and mobile widths inspect the total effect: framing, image loading, first-viewport hierarchy, text fit, captions, and the movement from image into evidence.

## Current Design Judgment

The first pass deliberately favors an editorial sequence over a portfolio grid. The homepage opens with one immersive image, returns to a quiet hiring path, then alternates evidence, photographs, and operating language. The Fair Rent page uses a longer sequence because the campaign's lineage is best understood through many rooms, materials, and public moments. Other project pages remain image-light until the archive yields a defensible, rights-reviewed selection.

This is a working composition, not the terminal edit. The system is designed to accept future photographs without requiring every discovery to appear on the public site.
