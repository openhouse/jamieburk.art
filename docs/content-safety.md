# Content Safety

This site is a selected professional proof surface, not a private archive.

Use public-safe summaries, collective-work language, approved material, and
representative artifacts. Do not publish private materials, unapproved names,
quotes, photos, screenshots, client details, raw transcripts, strategy notes,
credentials, internal dashboards, or source files. If approval is unclear, omit
the material.

## Default Rules

- Use public-safe summaries instead of raw source material.
- Use collective-work language where work was collaborative.
- Do not publish private emails, private notes, raw transcripts, or internal
  operating documents.
- Do not publish names, quotes, photos, screenshots, client details, or
  collaborator details without approval.
- Do not publish private or proprietary font files.
- Omit rather than expose when approval is unclear.
