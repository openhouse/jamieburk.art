# Source Index

This source index keeps the proofs bank auditable without turning the public
repo into an archive dump. It names public-safe source classes, public sources,
and approved local source summaries. It does not publish private records.

## Rules

- Use public source IDs directly in website footnotes, notes, or evidence copy
  only when the source itself is public and suitable for readers.
- Use archive-summary source IDs to support claim discipline inside the repo.
  Do not publish or attach the underlying private source files.
- If a source contains comments, private correspondence, raw meeting material,
  account/security material, personal data, or collaborator-private context,
  cite only the approved aggregate claim.
- If the source is not listed here, add it here before using it to strengthen a
  public claim.
