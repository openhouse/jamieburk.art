# Proofs Bank Sources

This source index keeps the claims auditable without turning the repo into an
archive dump. It names public-safe source classes and public sources. It does
not publish private source records.

## Canonical Source Rules

- Public sources may be linked when they are suitable for readers.
- Public-safe archive summaries can support aggregate claims, but the underlying
  private files stay outside the repo.
- If a source contains comments, private correspondence, raw meeting material,
  account/security material, personal data, or collaborator-private context,
  cite only the approved aggregate claim.
- Add a source here before using it to strengthen public wording.
