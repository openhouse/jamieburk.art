# Projection Guide

Proofs bank = public-safe source of truth.
Claim register = exact release wording.
Website = composed projection for hiring/referral readers.

The site should not mirror every claim. It should select the smallest set of
strong, audience-relevant claims that makes Jamie legible without overexposing
private source layers.

## Homepage

Use claims that answer quickly:

- What does Jamie do?
- What proof range supports the claim?
- Why is this credible for technical project management, product operations,
  implementation, and documentation work?

Best claim IDs: `PB-001`, `PB-003`, `PB-004`, `PB-007`, `PB-008`.

Avoid unresolved metrics, granular archive counts, legal/policy nuance, and
claims that require too much explanation.

## Work Index

Use the work index to show breadth. Each card should answer:

- role fit;
- what was unclear;
- what became usable;
- public-safety status.

## Case Studies

Use case studies for nuance:

- exact aggregate counts when approved;
- source-boundary notes;
- Known / Open / Protected sections;
- collaboration language;
- "what this does not claim" limits.

Sensitive case studies should show the public-safety note before representative
artifacts.

## Technical Operations

Use this page for transferable capabilities:

- requirements;
- workflow mapping;
- acceptance criteria;
- quality assurance and user acceptance testing;
- stakeholder updates;
- adoption materials;
- documentation architecture;
- source maps;
- decision records;
- durable handoffs.

Best claim IDs: `PB-001`, `PB-002`, `PB-004`, `PB-006`, `PB-010`.

## Resume Page

Use concise employer-legible proof. The PDF remains the canonical resume
artifact; the HTML page provides an accessible summary.

Do not show contact details on the page unless separately approved. The phone
number may appear only inside the approved PDF for V1.

## Lab Page

Use Source-Backed Team Memory as method / prototype:

- `PB-010`
- `PB-011`

Avoid finished SaaS, private archive browser, autonomous publication, and
client-adoption claims.
