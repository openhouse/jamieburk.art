# Proofs Bank

This directory is the public-safe source of truth for Jamie Burkart's portfolio
claims. It is a proofs bank, not the private archive.

The website should project from this bank: shorter, clearer, more audience-aware,
and optimized for referrals, interviews, and role fit. The bank can hold more
context than the site, but it must still be safe to publish in a public GitHub
repository.

## Model

- `claims.md` records defensible professional proof narratives.
- `sources.md` records source-basis labels, approval state, and where claims are
  used.
- `projection-guide.md` defines how the website may project from the bank.
- `../chad-lens.md` defines the editorial filter for professional legibility.
- `../release-checklist.md` defines staging, referrer, production, indexing, and
  rollback gates.

## Rules

- Do not publish raw transcripts, private correspondence, private coalition
  notes, legal review materials, unapproved photos, private contact details,
  confidential stakeholder lists, credentials, or raw community records.
- Use public-safe summaries, approved public artifacts, redacted examples,
  careful collective-work language, and exact collaborator credit where it has
  been approved.
- Claims should be easy to weaken and hard to overstate. Prefer "contributed to a
  period of 2x revenue growth" over "drove 2x revenue growth" unless the stronger
  causal claim is separately approved.
- There is no public `/proofs` page. The bank is a repo-level working record; the
  site selects from it.

## Source-Basis Labels

- approved public resume PDF
- public website / public project artifact
- public reporting / public-source note
- public-safe portfolio brief
- aggregate review without private rows
- Jamie review confirmation
- collaborator approval pending
- approval needed
