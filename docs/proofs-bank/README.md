# Proofs Bank

This directory is the public-safe knowledge base for Jamie Burkart's professional
accomplishments.

The website is a projection of this bank. The bank keeps the stronger underlying
claims legible; the site selects, compresses, and sequences those claims for a
specific audience.

Everything in this directory must be safe to publish in a public repository.
Do not include private emails, raw transcripts, private coalition notes,
legal-review materials, stakeholder lists, private contact records, customer
data, credentials, unapproved photos, internal analytics, private financial
records, or raw community records.

## Claim Rules

Each proof entry should answer:

1. What is the strongest accurate claim?
2. What public-safe wording can the website use?
3. What is the source status?
4. What should not be said?
5. Where does this claim project into the website?

Prefer concrete systems, durable artifacts, aggregate counts, public records,
and careful role language. Avoid causal overclaiming, sole-credit language for
collective work, and exact metrics that cannot be defended in public.

## Source Status

- `Public record`: supported by public press, public government records, public
  repositories, or public websites.
- `Approved resume`: supported by the public resume included in this repo.
- `Public-safe aggregate`: supported by aggregate analysis of private archives;
  only the aggregate claim belongs here.
- `Private source, public-safe summary`: underlying material is private, but the
  summary is safe and bounded.
- `Candidate`: plausible or true from private context, but not yet strong enough
  for prominent website copy without Jamie approval or cleaner public evidence.
