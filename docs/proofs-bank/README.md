# Proofs Bank

This is the public-safe editorial knowledge bank for Jamie Burkart's portfolio.
It is not a private archive, source dump, transcript browser, legal-review
folder, screenshot repository, or confidential evidence room.

The website should be a clear projection of this bank, not a dump of the
underlying evidence. Public pages may draw only from claims marked `approved`
or `public-safe` in `claims.md`.

Unapproved claims belong in the release process, not in the public reader's
path.

## Use Order

1. Start with `claims.md`.
2. Check `source-classes.md` for the evidence posture.
3. Check `approval-status.md` before promoting stronger metrics, screenshots,
   names, or contact details.
4. Apply `../chad-lens.md` before projecting a claim into website copy.

## What Stays Out

Do not add raw transcripts, private coalition notes, legal-review materials,
private correspondence, confidential company details, customer/user records,
stakeholder lists, raw community records, unapproved screenshots, unapproved
photos, unapproved quotes, private fonts, credentials, private source paths, or
private contact details.

## Projection Rule

The site should make Jamie legible without asking a hiring reader to decode
Jamie's whole world. It should answer:

- What did Jamie do?
- Toward what end?
- What became usable?
- Why is this relevant to technical operations, product operations, or
  implementation?
- What remains protected?

Use careful collective-work language where the work was collective.
