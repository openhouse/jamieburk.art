# Public Claims Bank

This is the canonical public professional claims file for the site. Add or
revise public claims here before projecting them into website copy or
structured site data.

## Status Vocabulary

- `approved`: Jamie has approved this exact public wording.
- `public-safe`: safe general wording; stronger specifics may still require
  approval.
- `needs_jamie_review`: do not project into public site yet.
- `hold_for_interview`: useful claim, but better for interview context.
- `private_do_not_publish`: never publish.
