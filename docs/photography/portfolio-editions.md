# Portfolio Editions

A portfolio edition is a dated, Git-bound set of public occurrences and page
compositions. It lets the team discuss Layout C, Layout E, and future
compositions without treating one arrangement as the archive's final meaning.

An occurrence binds:

```text
image + derivative + crop + typography + copy + caption + credit
+ sequence + viewport + action + release state
```

The same source may have several derivatives and historical occurrences. Rights
and approval never attach to the photograph in the abstract.

The first recorded edition is `edition.layout-c.2026-07`. Its East River
occurrence is preserved as a corrected historical candidate on hold. Jamie's
exact-occurrence review, dignity review, creator crop review, production, and
indexing remain open. Layout E continues to be authored in the application;
this RFC does not automatically replace its homepage.

Generated edition reports describe authored records. They do not choose page
order, prominence, component, narrative sequence, or whether an image appears.
