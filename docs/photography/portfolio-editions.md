# Portfolio Editions

A portfolio edition is a dated, Git-bound composition for one audience and
purpose. It records exact image occurrences and intentional protected absences.

An occurrence binds:

```text
derivative + route + component + crop + caption + credit
+ sequence + viewport + release state
```

The Wiki may expand additively. The portfolio composes subtractively. A later
edition may use a different image or no image without rewriting the earlier
decision as a mistake.
