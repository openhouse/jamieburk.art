# Photography Pull-Request Template

## Visitor Problem

What comprehension, orientation, memory, feeling, or action need does this
image or sequence address?

## Composition

- Why this image?
- Why this page and position?
- Which crop, typography, copy, caption, credit, sequence, viewport, and action
  were reviewed together?
- What changed between blind and contextual review?
- Which related frames, meaningful alternative, and no-photo version were
  considered?

## Documentary Boundary

- What can the image establish?
- What may it evoke or open?
- What does it not establish?
- Which caption assertions resolve to supported statement IDs?

## Rights and Care

- What creator, custody, permission, represented-person, artwork, dignity, and
  collective-credit states apply?
- Which public-Git, staging, production, and indexing gates remain open?
- What remains protected?

## Knowledge Return

- What changed in the Knowledge Wiki?
- Did the encounter create a recollection, correction, inquiry, hold, or
  no-action response?
- How can the occurrence be withdrawn, corrected, or superseded?

## Verification

- [ ] `npm run photos:check`
- [ ] `npm run photos:test`
- [ ] `npm run photos:report`
- [ ] Exact-candidate responsive and accessibility review
- [ ] Human gates listed without being converted into automated passes
