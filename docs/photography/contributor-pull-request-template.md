# Photographic knowledge contribution

Use this outline when proposing a public-safe photo record or correction.

## Proposed change

State the asset, occurrence, recollection, correction, or research question.

## Public-safe basis

List only evidence that may safely appear in a public repository. Describe any
private support by bounded status, never by raw quotation or locator.

## Observation and interpretation

Separate what is visibly observable from metadata, memory, and curatorial
interpretation.

## Rights and people

Record photographer, permission scope, represented-person review, visible
artwork, collective credit, caption, crop, and destination state separately.

## Affected occurrences

List every route, component, derivative, and portfolio edition that may change.

## Open gates

Name unresolved human decisions. A pull request and green checks do not close
them.

## Verification

Run:

```bash
npm run photos:check
npm run photos:test
npm run photos:report
npm run wiki:check
```
