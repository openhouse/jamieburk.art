# East River Canary

The canary connects one existing public derivative to one asset record, one
photo set, statement-level provenance, one permission summary, one curatorial
proposal, one decision, one public occurrence, one portfolio edition, one
recollection, and one research inquiry.

## Walkthrough

1. Read the [asset record](../knowledge-bank/assets/photographs/east-river-manhattan-bridge-2022.md).
2. Confirm the derivative checksum and dimensions with `npm run photos:check`.
3. Read the [permission summary](../knowledge-bank/sources/permissions/elana-gordon-east-river-portfolio-2026.md).
4. Compare the [curatorial proposal](../knowledge-bank/evaluations/curatorial/layout-d-home-east-river-v1.md) with the [selection decision](../knowledge-bank/decisions/photography/layout-d-home-east-river-v1.md).
5. Inspect the [homepage occurrence](../knowledge-bank/projections/photography/layout-d-home-east-river.md) and [portfolio edition](../knowledge-bank/projections/photography/layout-d-portfolio-edition.md).
6. Follow the encounter to the [recollection](../knowledge-bank/sources/recollections/jamie-canoe-commuting-2026-07.md) and [research inquiry](../knowledge-bank/research-inquiries/documented-canoe-bike-journeys.md).

## Open Gates

- independently verify the private source binding;
- reinspect the private permission evidence before production;
- approve the final crop and production release;
- observe staging;
- approve indexing separately.

The canary is implementing, not operational. Its public records say exactly
where the loop closes and where it still stops.
