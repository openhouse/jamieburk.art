# Recollection and Correction

Seeing a public composition may return new knowledge to the archive. Record that
return without silently rewriting the page.

A recollection states:

- who is remembering;
- when the account was recorded;
- what prompted it;
- what is remembered;
- what remains uncertain;
- which public claim, if any, is authorized.

A correction states the earlier record, the preferred replacement, source
basis, affected occurrences, and whether the current site must change.

For the East River canary, Jamie's recollection describes a recurring
bicycle-canoe transportation practice and the multi-use coupling design. The
record opens a research inquiry. It does not establish a journey count and does
not enlarge the concise public caption.

Use:

```bash
npm run photos:recollection -- asset.photo.east-river-manhattan-bridge.2022.001
```

The command prints a public-safe scaffold. A human still decides whether and
where to save it.
