# Photography

> **Artists choose. Archival production supports. The Knowledge Wiki remembers.
> Rights govern. The portfolio composes. Jamie decides what becomes public.**

This is the public-safe operating guide for RFC 0003's living photographic
knowledge loop. Start with the [East River canary](east-river-canary.md).

## Three Questions

- **Metadata asks:** Why might this photograph be relevant?
- **Visible evidence asks:** What can an editor actually see?
- **Provenance asks:** What can we responsibly claim?

Do not collapse those answers. A later recollection may deepen the Wiki without
becoming a caption fact. A rights-cleared asset may remain unselected. A
selected photograph may remain blocked from production.

## Five Public Records

1. **Asset:** stable public-safe identity and supported statements.
2. **Public derivative:** one metadata-minimized file for bounded uses.
3. **Curatorial proposal and decision:** alternatives, dissent, and human
   authority.
4. **Public occurrence:** one derivative in one exact composition.
5. **Portfolio edition:** a dated, reviewable set of occurrences and absences.
