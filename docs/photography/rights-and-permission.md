# Rights and permission

Review each occurrence across separate dimensions:

1. creator attribution;
2. photographer copyright or use permission;
3. archive custody;
4. represented-person dignity and privacy;
5. visible artwork or third-party rights;
6. collective-credit accuracy;
7. caption accuracy;
8. crop acceptability;
9. exact destination;
10. public Git, staging, production, and indexing approval.

One green `rights` Boolean is insufficient. Public Git is publication, but
authorization for branch review is not production permission or unrestricted
reuse.

Private correspondence remains outside Git. A public record may state the
bounded result and a public-safe status, but it must not contain the
correspondence, a private locator, or an identifying fingerprint.

Revocation blocks future builds for the affected occurrence, opens a correction
record, and removes or replaces the derivative through an explicit pull
request. Historical use is preserved without exposing a private reason.
