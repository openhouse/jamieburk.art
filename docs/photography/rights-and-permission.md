# Rights and Permission

Public Git is publication. An unmerged branch, draft pull request, or noindex
staging page is not a private review surface.

Track these dimensions independently:

- creator attribution;
- copyright or use permission;
- archive custody;
- represented-person dignity and privacy;
- visible artwork and third-party rights;
- collective-credit accuracy;
- caption accuracy;
- crop acceptability;
- exact destination;
- public-Git, staging, production, and indexing approval.

A permission capsule stores only a bounded public-safe result and an opaque
pointer. Raw correspondence, contact details, and private evidence remain
outside the repository. Revocation blocks affected occurrences and opens a
correction; it does not erase history.
