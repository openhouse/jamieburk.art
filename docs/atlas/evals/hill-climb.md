## Recursive iterations

1. The architecture-only A-N manifest was rejected as insufficient for the
   stricter knowledge-integration request.
2. An immutable source-artifact catalog and one Markdown page for every
   canonical project key were added. The migration gate exposed five entities
   linked only through inbound relationships.
3. Project slices changed to traverse the declared entity neighborhood in both
   directions. Canonical collection coverage reached 100 percent.
4. A named-credit register and mutation gate were added. The gate caught Tom
   Finkelpearl and Anne Dufy Burkart names broken across Markdown line wraps;
   the pages were corrected without weakening the check.
5. A privacy probe found six malformed Google-document locators whose embedded
   line breaks evaded host classification. Locator handling was hardened and
   the catalog regenerated; protected entries expose hashes only.
6. A second complete catalog build produced the identical byte-level SHA-256,
   and the frozen source trees matched all committed artifact mappings.
7. Moving source heads were refreshed by exact commit while Atlas was being
   evaluated, incorporating new coalition, Call Script, WOW List, Sunday
   Dinner, NYC Artist Coalition, and KC Spaces Fund knowledge.
8. A source catalog alone was rejected as insufficient for future operation.
   Atlas gained a 1,044-record canonical store, compatibility adapters, exact
   legacy parity, direct consumer migration, and an eval rejecting future
   imports from deprecated banks.
9. The first full-fidelity history eval failed because two source heads were
   not Atlas ancestors. A tree-preserving merge made their histories and blobs
   reachable without changing Atlas files.
10. Review found that production preflight used the source-only gate and that
    Playwright was undeclared. The release contract and dependency were fixed,
    regression-tested, and rerun from a clean installation.
11. The Wikipedia comparison was converted into a versioned v4 suite rather
    than prose-only recommendations. Every declared result is now checked for
    exact implementation coverage.
12. The first v4 run exposed structured variants whose identifier families
    were omitted from the catalog vocabulary. The parser was tightened to an
    explicit whole-value vocabulary and expanded to cover AST, CAP, EVID, INT,
    LEAD, OBS, and the other inherited record families. Addressable semantic
    identities rose from 5,695 to 7,650 without flattening variants.
13. The temporal gate rejected an honest year-only source value. Atlas adopted
    ISO reduced precision (`YYYY`, `YYYY-MM`, full dates, or timestamps) rather
    than inventing precision not present in the source.
14. The lineage gate then rejected a stale candidate after implementation
    changed. The accepted run was rebound to the exact current candidate and
    compiled inputs.
15. Eighteen new contract and mutation tests deliberately removed provenance,
    dispositions, evidence, credit, ontology inverses, navigation, and result
    declarations; corrupted time, aggregate totals, retrieval answers, rights,
    protected locators, and source blobs; revived corrected wording; and
    attempted to self-certify a human gate. Every mutation was detected.
16. A clean-room bundle materialized all portable files and 1,676 source blobs,
    verified without Git, and then failed as designed after one blob was
    corrupted. Two complete source-catalog regenerations remained byte-identical.
17. The accession-exit question exposed 236 artifact associations with no prior
    semantic-record, variant, document, locator, or stakeholder target. Atlas
    evolved rather than discarding them: every artifact now has a native source
    object, format-aware profile, knowledge classes, and explicit component
    disposition across Markdown, JSON, JSONL, CSV, TypeScript, JavaScript, HTML,
    and plain text.
18. Git blob addresses were demoted from content protocol to historical
    accession provenance. SHA-256 `atlas://source-objects/...` identities,
    profile addresses, native dataset/procedure/evaluation/narrative targets,
    and a bundle-native reader became the consumer surface.
19. The v5 suite added 20 hard gates, 3 quality targets, and 3 human gates for
    migration closure, semantic and structural parity, privacy, provenance,
    fixity, Git independence, human inspectability, and situated fidelity.
20. The first normalized v5 catalog passed but grew to 53 MB by duplicating
    semantic edges inside both artifact and source-object records. That design
    was rejected for pull-request inspectability. Semantic components now own
    their native addresses once; artifact dispositions keep only object,
    profile, and format-protocol targets. The catalog fell to 34 MB while the
    same parity gates remained strict.
21. Four deduplicated source objects appeared in more than one situated
    artifact role. Source objects now retain the exact union of knowledge
    classes and native targets from every accession location; an adversarial
    mutation proves that deduplication cannot collapse those roles.
22. Thirty-six named mutations now exercise the earlier v4 invariants and every
    new accession-exit gate. Native bundle retrieval answers the grounded KC
    Spaces Fund task without Git after materialization and rejects deliberately
    corrupted source-object bytes.
