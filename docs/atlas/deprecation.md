# Deprecated knowledge-bank and source-ingestion protocols

The knowledge banks used during prototype development are frozen reference
fixtures. They are not future authoring surfaces or runtime dependencies. New
work depends on Atlas canonical records, semantic pages, source dossiers, and
content-addressed source objects.

For source ingestion, the following are deprecated:

- multiple ingestion or interpretation records for one source artifact;
- processing branch, commit, path, or implementation as source provenance;
- ensemble comparison as a retained knowledge component;
- branch/path artifact lookup in the Atlas service or CLI; and
- generated migration catalogs as a human editorial surface.

The frozen catalog remains temporarily as an internal parity and recovery
fixture for the earlier migration. It is excluded from the consumer-facing
compiled graph and query service. Its presence does not authorize future
source ingestion through those structures.

Corrections create Atlas correction relationships and revised governed
components. They do not rewrite the protected artifact or multiply canonical
source identity. If a correction reveals an unsupported knowledge form, Atlas
must evolve before the correction can be accepted.
