# Knowledge Bank

This site is a public-safe professional proof surface, not a full archive.

The knowledge bank is the governed source of truth for claims about Jamie's
work. It records public claims, safer short wording, support levels, approval
status, role-fit capability, projection surfaces, and protected boundaries
before a claim appears on the website.

## Source Of Truth

The canonical structured data file is:

`apps/www/src/data/proofs.ts`

Website surfaces should project from that file wherever practical:

- homepage proof strip
- resume page highlights
- Technical Operations proof page
- work case studies
- Source-Backed Team Memory lab page

## Operating Rule

Every public-facing work entry should answer:

1. What was unclear?
2. What did Jamie do?
3. Toward what end?
4. What became usable?
5. What remains protected?

## Approval Discipline

Use softened V1 wording by default. Keep exact metrics, named collaborators,
screenshots, photos, quotes, and private-source details approval-gated unless
Jamie has explicitly approved the exact public context.

Private materials stay outside the repo. The scanner is a backstop, not the
primary privacy strategy.
