# Public Proofs Bank

This is the public-safe knowledge base for Jamie Burkart's professional
accomplishment claims. Treat it as the source bank the website projects from:
the repo is public, so every claim here must be acceptable if quoted in a
newspaper.

## Claim Standard

- Use the strongest accurate claim, not the loudest claim.
- Make Jamie visible as an actor without erasing collaborators.
- Prefer contribution language when causal ownership is shared or internally
  evidenced.
- Prefer concrete deliverables over abstract labels.
- Keep historical prototypes clearly historical.
- Keep sensitive source material offline; publish public-safe summaries,
  aggregate counts, public links, and approved wording.

## Chad Lens

Before adding a claim to the site, ask:

1. Is Jamie visible as the actor?
2. Does the sentence answer "toward what end?"
3. Would a hiring manager understand it without decoding an internal phrase?
4. Are collaborators credited by using careful collective-work language?
5. Is the claim strong enough to respect the record and careful enough to defend?
