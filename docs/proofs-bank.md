# Proofs Bank

This is the public-safe knowledge base for Jamie Burkart's professional
accomplishments. It is not a private archive and not a full evidence room.

The website should be a projection of this bank: shorter, clearer, and shaped
for the audience in front of it. The bank can hold stronger claim language and
boundaries; the website should choose the claims that make Jamie's role legible
without publishing protected context.

## Publishing Rule

Use only claims that could appear in a newspaper without harming a person,
coalition, client, employer, tenant, cultural space, business, or collaborator.

Do not add raw transcripts, private notes, private correspondence, contact data,
credentials, internal dashboards, legal-review context, private source files,
unapproved photos, stakeholder lists, raw community records, or private local
paths.

## Claim Status

- Defensible: strong enough for portfolio copy when phrased with the stated
  boundaries.
- Use with care: usable in summary form, but the exact wording should remain
  conservative.
- Open: needs a confirmed public citation, screenshot approval, collaborator
  approval, or stronger source review before public launch.
- Protected: intentionally omitted because privacy, consent, client trust, law,
  civic sensitivity, or community safety requires it.

## Projection Guidance

When writing website copy from this bank:

- Put Jamie back into the sentence as the actor.
- Preserve collective-work language where the work was collective.
- Prefer "built", "structured", "translated", "stewarded", "mapped",
  "coordinated", and "made usable" when those are the actual moves.
- Use aggregate metrics only when they clarify scale.
- Move exact citations, unresolved approvals, and sensitive evidence into docs
  or review notes, not public UI.
- Keep the public site shorter than the bank. The bank exists so the site can be
  clear without becoming thin.
