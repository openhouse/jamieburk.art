- `apps/www/src/data/proofs.ts`

Do not create a public `/proofs` website page for V1. The proof bank is a
repo-internal source of truth. The website is a rhetorical projection of that
source of truth, optimized for clarity, audience, and purpose.

## Projection Principle

The homepage should show the safest, clearest proof strip. Role pages should
show role-fit proof. Work pages should show local context, boundaries, and
transferable evidence. Private source records stay outside the repo.
