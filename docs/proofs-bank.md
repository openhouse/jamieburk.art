# Proofs Bank

This repo is public. Treat this document and the structured proof data in
`apps/www/src/data/proofs.ts` as newspaper-safe material: if a sentence would be
unsafe, unfair, too private, or too hard to defend in public, it does not belong
here.

The website is a projection of this bank. The bank can hold more structure than
the website shows: canonical claim language, evidence posture, publication
guidance, and boundaries. The website should use the clearest subset for a
specific audience and purpose.

## Standard

Every proof should answer five questions:

1. What is the strongest defensible public claim?
2. What was Jamie's accurate role?
3. What is the support level for the claim?
4. Where should this claim appear on the site?
5. What must not be published?

## Approval-Gated Claims

These may become usable later, but should not be published as current website
copy without an approved public source package:

- Exact public-funding numbers for KC Town Hall.
- Named collaborator, stakeholder, client, or participant claims beyond already
  approved public credits.
- Screenshots, photos, direct quotes, private correspondence, raw meeting notes,
  raw transcripts, raw community records, or contact lists.
- Detailed HJE revenue breakdowns, private analytics dashboards, customer data,
  vendor terms, internal operations, or credentials.
- Any CRS claim that makes Jamie the campaign lead rather than a documentation
  systems lead and coalition-operations support contributor.
- Any WOWList claim that treats geocoded coverage as official local chapters.

## Update Rules

- Add the public-safe canonical claim first.
- State the basis in general terms without naming private files or exposing raw
  private source material.
- Add explicit boundaries before projecting a claim onto the website.
- Prefer rounded aggregate metrics when the underlying record contains private
  user, customer, participant, financial, or stakeholder detail.
- Use `contributed to`, `helped`, `co-built`, `supported`, or `stewarded` when
  the record supports material contribution but not sole ownership.
