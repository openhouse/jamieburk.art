# Proofs Bank

This repository is public. Treat this proof bank as a newspaper-safe internal
source-of-truth structure: if a claim, source description, caveat, or
collaborator reference would be unsafe in a public article, it does not belong
here.

The website is a projection of this bank. The bank keeps the claim discipline;
the site translates it for hiring managers, collaborators, and referrers.

For machine-readable claim structure, use `docs/proofs-bank.json`. This Markdown
file explains the public-safe rationale, boundaries, and projection guidance.

## Claim Rules

- State the work Jamie did, not the private material used to understand it.
- Use collective language where the accomplishment was collective.
- Prefer "helped build", "contributed to", "supported", "structured", and
  "stewarded" when the evidence supports participation but not sole authorship.
- Keep metrics aggregate and source-backed. Do not publish raw records.
- Separate public outcomes from Jamie's role in the operating infrastructure.
- Keep Known / Open / Protected boundaries explicit.

## Evidence Posture

Known:
Public-safe and evidence-backed enough to say on the site.

Open:
Potentially useful, but needs approval, stronger citation, screenshot review,
or collaborator confirmation before being promoted.

Protected:
Intentionally omitted because privacy, consent, client trust, legal review,
civic sensitivity, or community safety requires it.
