# Public-Safe Proofs Bank

This is the approved public-safe source of truth for Jamie Burkart's
professional proof. The website projects from this bank; it should not project
directly from private archives, memory, scattered component copy, or unreviewed
source folders.

This repo is public. Every claim here should be acceptable if quoted in a
newspaper. Keep private emails, raw transcripts, private coalition notes,
legal-review materials, stakeholder lists, client-private material, raw
community records, internal analytics, unapproved photos, unapproved quotes, and
private contact records out of the repo.

## Publishing Standard

- Use the strongest accurate claim, not the loudest claim.
- Make Jamie visible as the actor without erasing collaborators.
- Say toward what end the work existed.
- Explain what became usable.
- Use softened claims for V1 unless exact metrics are explicitly approved.
- Keep protected evidence offline; use public-safe summaries, aggregate counts,
  public links, redrawn artifacts, or approved screenshots.
