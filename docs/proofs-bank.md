# Proofs Bank

This document is the public-safe knowledge base for Jamie Burkart's professional
accomplishments. It is intentionally not a private archive. The website should be
a clear projection of this bank for hiring managers, referrers, collaborators,
and aligned paid work.

## Use Rules

- Use only newspaper-safe facts in this repo.
- Keep private source materials outside the repo.
- Do not publish raw emails, transcripts, guest lists, attendance records,
  stakeholder lists, legal-review notes, customer data, dashboards, credentials,
  private financial detail, private property detail, or unapproved images.
- Use precise contribution language where work was collaborative.
- When a claim depends on private evidence, publish only the aggregate claim and
  the public-safe evidence basis.
- The website should optimize for audience and purpose; it does not need to show
  every proof in this bank.

## Claim Strength

- Strong: public record, press coverage, public website, or public-safe aggregate
  evidence supports the claim.
- Supported: private evidence has been reviewed, but raw material stays outside
  the repo.
- Hold: plausible or remembered, but not yet ready for public use.
