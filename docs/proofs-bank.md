# Professional Proofs Bank

Status: public-safe knowledge base for Jamie Burkart's professional accomplishment claims.

This file is part of a public repository. Treat every sentence as something that could be quoted in a newspaper. Do not add private paths, raw transcripts, private coalition notes, private correspondence, client-private material, nonpublic stakeholder lists, raw user records, unapproved phone numbers, unapproved photos, or unapproved quotes.

The website is a projection of this bank, not a copy of it. Site pages should select, simplify, and sequence claims for a specific audience while preserving the limits recorded here.

## Publishing Standard

- Use the strongest accurate claim, not the loudest claim.
- Prefer concrete nouns: requirements, workflows, source maps, decision records, launch support, public guidance, handoffs, catalog systems, action trackers, and public-data framing.
- Use helped / supported / contributed to / co-built where work was collective.
- Name public organizations, public projects, and public campaign surfaces only when the source is already public or Jamie has approved the framing.
- Keep protected evidence out of the repo. It may inform confidence, but it should not become public proof.
- Do not publish raw evidence to solve a credibility problem. Use a public-safe summary, redrawn artifact, public source link, or omit the claim.

## Claim Levels

**Core public claim:** Safe for homepage, about page, resume alignment, metadata, and high-level profile language.

**Case-study claim:** Safe on a relevant work page when the page includes scope, role, and limits.

**Proof-strip claim:** Short enough for homepage proof modules; must be especially conservative.

**Approval-needed claim:** Factually plausible or supported, but needs Jamie, collaborator, artifact, screenshot, or metric approval before production indexing.

**Do-not-use claim:** Overbroad, unsupported, private, or likely to distort collective work.
