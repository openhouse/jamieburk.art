# Proofs Bank

This document is the public-safe knowledge base for Jamie Burkart's professional
accomplishments. It is intentionally not a private archive and not a public web
route. Nothing here should publish private source material, private
correspondence, private contact lists, unapproved photos, internal business
records, review-sensitive materials, or raw community records.

The website is a projection of this bank. It should select the smallest set of
claims that makes Jamie legible to hiring readers, referrers, collaborators, and
public-interest technology teams. The bank can hold more context than the site,
but it must stay newspaper-safe.

## Source-Basis Labels

Use these labels instead of publishing private source text:

- Public campaign page.
- Public-safe portfolio brief.
- Aggregate workbook review with no names, contacts, addresses, or private rows.
- Public-safe source bundle reviewed by Jamie.
- Protected evidence held offline.
- Collaborator approval pending.

## Claim Strength

- Strong: public record, public artifact, press coverage, approved resume, or
  aggregate public-safe evidence supports the claim.
- Supported: protected evidence has been reviewed, but raw material stays
  outside the repo.
- Hold: plausible or branch-family-surfaced, but not yet ready for public use.

## Review Protocol

Before adding a new public claim:

1. Add the claim here with source-basis category and public-use note.
2. If it is intended for the website, add exact wording to
   `docs/public-claims-inventory.md`.
3. Confirm the wording uses the right agency: helped, contributed, co-built,
   stewarded, hosted, documented, supported, or led.
4. Confirm no private names, contact details, sensitive records, or unapproved
   images are exposed.
5. Run public-safety and release checks before production indexing.
