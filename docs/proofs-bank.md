# Proofs Bank

This file is the public-safe source bank for Jamie Burkart's professional
accomplishment claims.

The website should project from this bank. It should not invent stronger claims
in components, MDX, or metadata.

This repo is public. Nothing here should publish raw evidence, private paths,
transcript excerpts, private correspondence, private contact lists, unapproved
photos, internal business records, legal-review materials, or raw community
records.

## Claim Standard

- Use the strongest accurate claim, not the loudest claim.
- Make Jamie visible as an actor without erasing collaborators.
- Prefer contribution language when causal ownership is shared.
- Prefer concrete deliverables over abstract labels.
- Keep historical prototypes clearly historical.
- Keep sensitive source material offline; publish public-safe summaries,
  aggregate counts, public links, and approved wording.

## Review Protocol

Before adding a new public claim:

1. Add the claim here with support level and boundaries.
2. If it is intended for the website, add exact wording to
   `docs/claim-register.md`.
3. Confirm the wording uses the right agency: helped, contributed, co-built,
   stewarded, hosted, documented, supported, designed, or built.
4. Confirm no private names, contact details, sensitive records, or unapproved
   images are exposed.
5. Run public-safety and release checks before production indexing.
