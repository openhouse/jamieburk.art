# Source-Backed Team Memory Opportunity

The small project to propose is a Source-Backed Team Memory Sprint: a bounded
1-2 week engagement to help a fast-moving team preserve decisions, source
context, open questions, and onboarding knowledge without creating a heavy
knowledge-management system.

The goal is not "more notes." The goal is to prevent valuable ideas from being
left on the cutting-room floor and to make team memory inspectable, correctable,
and useful.

Public page:

https://jamieburk.art/lab/source-backed-team-memory

## Bounded Offer

- Select a small source set: meetings, docs, decisions, product notes,
  transcripts, or onboarding materials.
- Build a source map: what exists, where it lives, what is reliable, what is
  missing.
- Create a decision-memory template: decisions, rationale, owners, open
  questions, next steps.
- Produce onboarding context for a new collaborator's first week.
- Add a human-review workflow: AI drafts, humans correct, uncertainty remains
  visible.
- Deliver a continue / revise / stop recommendation.

## Boundary

This is an early method / consulting practice, not a finished SaaS, not an AI
replacement for judgment, and not a private archive browser.
