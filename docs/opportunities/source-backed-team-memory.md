# Source-Backed Team Memory Opportunity

## Positioning

Source-Backed Team Memory is a bounded lab / method for helping
knowledge-heavy teams preserve decisions, open questions, onboarding context,
meeting memory, and source-linked rationale in a human-reviewable way.

## Best Public Links

- Lab page: https://jamieburk.art/lab/source-backed-team-memory
- Technical Operations: https://jamieburk.art/work/technical-operations

## Boundary

Do not pitch this as production SaaS, a private archive browser, a chatbot, or
an AI replacement for human judgment.
