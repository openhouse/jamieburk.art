# Civic, Cultural, And Technical Translation

Jamie often works where different actors use different codes: a resident tells
a story, an organizer recognizes a pattern, a public servant needs a bounded
requirement, and a technical system needs fields, states, routes, and ownership.
Translation does not make those actors interchangeable. It creates artifacts
different actors can use without pretending they hold the same role.

## Observable Forms

- meeting patterns that help lived experience enter shared deliberation;
- call scripts, maps, fact sheets, sponsor states, and public explanations that
  make action legible;
- data questions and provenance records that separate what is known from what
  remains unresolved;
- websites and identity systems collaborators can operate from shared public
  material; and
- requirements, decision records, documentation, and handoff structures that
  make implementation inspectable.

## Professional Value

This is useful in technical project management, product operations,
implementation, civic technology, public-interest technology, and other work
where delivery crosses organizational or disciplinary boundaries. The record
supports translation and implementation; it does not establish that Jamie
speaks for every community, owns institutional decisions, or authored every
artifact that moved through a shared system.
