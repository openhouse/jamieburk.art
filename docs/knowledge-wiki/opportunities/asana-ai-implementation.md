# Asana AI Implementation Manager Opportunity

The current portfolio supports implementation judgment, workflow mapping, and
human-reviewed AI practice. It does not yet establish formal enterprise SaaS
migration ownership. That boundary belongs in the role record and interview,
not behind inflated website language.

Begin with [Technical Operations](../capabilities/technical-operations.md) and
the [Source-Backed Team Memory method](../methods/source-backed-team-memory.md).
