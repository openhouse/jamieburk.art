# Professional Legibility

This document preserves the editorial lens for the portfolio. Do not quote or
name private reviewers, private job-search conversations, or private advisor
comments in public repo content.

## Standard

Minimize the reader's burden.

Make Jamie visible as the actor.

Translate specialized language.

Use action verbs.

Explain each project's purpose: toward what end?

Show what became usable.

Avoid unsupported ownership claims.

Prefer careful collective-work language.

Do not let tool lists make Jamie disappear.

Do not publish unapproved contact info, exact metrics, screenshots, collaborator
names, quotes, photos, or private materials.

## Page Checklist

Every public-facing work entry should answer:

1. What was unclear?
2. What did Jamie do?
3. Toward what end?
4. What became usable?
5. What remains protected?

## Voice

Precise, warm, modular, ethically grounded.

Documentation is care.

Do not overclaim.
