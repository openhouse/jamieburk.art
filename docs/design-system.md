# Design System

The visual system should feel practical, public-safe, and readable: a professional proof site with civic/poster energy in controlled places.

## Type

Karla is the body, interface, navigation, card, metadata, and documentation voice.

Oswald is the display and public-notice accent voice. Use it sparingly for hero eyebrows, selected section kickers, proof-strip emphasis, large case-study labels, and compact metadata headings. Do not use it for paragraphs.

Do not add Trade Gothic, Verlag, Gotham Rounded, Risque, handwriting fonts, private font files, or other unlicensed/private fonts without explicit rights and production-ready files.

## Color

Broadway blue, `#0b5f81`, is the primary civic/action accent for links, active states, rules, and focused UI.

The oil-pastel palette supports category dots, proof chips, diagrams, colophon swatches, and annotation moments. Keep the homepage restrained so the professional frame stays clear.

## Layout

Use the quiet grid and golden-ratio-inspired spacing already in the scaffold. Preserve a role-first homepage: name, role, and operating-structure statement should be legible in the first viewport.

## Components

daisyUI provides primitives such as buttons, badges, cards, alerts, and accessible state behavior. The site's personality should come from Jamie's content, the type system, Broadway blue, oil-pastel accents, and the measured grid.
