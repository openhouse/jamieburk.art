# Design System

The V1 visual system supports a professional proof site, not a decorative archive.

## Principle

Golden-ratio proportion + oil-pastel-derived color + Broadway blue + calm type hierarchy + print-derived layout discipline.

## Color

Primary action color: Broadway blue `#0b5f81`.

Default UI:

- Paper: `#eeefec`
- Surface: `#fffdf8`
- Ink: `#343435`
- Muted: `#5e5f61`
- Line: `#d9d9d6`

Oil-pastel colors should be supporting accents for tags, category moments, and recreated diagrams. Do not use all colors at once.

## Typography

Use Karla or system sans for V1. Proprietary fonts should not be committed unless Jamie explicitly confirms rights and provides webfont files.

## Layout

Use a centered page frame with golden-ratio spacing tokens. Case studies may use a 61.8% / 38.2% split on wide screens. Cards are reserved for repeated items, callouts, and framed tools.

## Accessibility

Maintain semantic HTML, visible focus states, WCAG AA contrast, responsive layouts, no autoplay media, and support for `prefers-reduced-motion`.
