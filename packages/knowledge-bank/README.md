# Knowledge Bank Package

`@jamie-burkart/knowledge-bank` is the single canonical machine-readable citation
layer for this monorepo.

The package keeps sources, atomic claims, evidence relationships, editorial
citation groups, page plans, research runs, correction history, and governed
artifacts distinct. Citation numbers are generated per page and are never stored.

The package is public-safe repository data, not a private archive. Protected
records retain only bounded metadata needed to prevent future overclaiming or
accidental publication.

See `docs/knowledge-bank/citation-policy.md` for the authoring and review workflow.
