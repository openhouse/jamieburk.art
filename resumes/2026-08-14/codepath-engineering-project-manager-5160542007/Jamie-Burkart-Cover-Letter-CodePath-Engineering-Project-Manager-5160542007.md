# Cover Letter - CodePath Engineering Project Manager

August 20, 2026

Dear CodePath Engineering Team,

A bug report is a small document with a large social job. It has to preserve what someone encountered, make the expected behavior clear, give an engineer enough evidence to act, and let the reporter know when the loop has actually closed. I am drawn to CodePath's Engineering Project Manager role because it joins that hands-on quality work with the quieter operating structure that keeps a small team moving.

For more than fourteen years through Thick Arts, I have led web products from ambiguous requests through requirements, implementation, testing, public release, issue resolution, and maintenance. I work directly with JavaScript and TypeScript, React and Next.js, Python and Django, SQL, Git and GitHub, Docker and Dokku, APIs, analytics, and application logs. I reproduce defects, record expected and actual behavior, write acceptance criteria and test cases, inspect fixes, and keep release decisions traceable. With WOWList, I also co-built and operated a Django, PostgreSQL/PostGIS, and Ember.js platform while coordinating product decisions, organizer support, releases, and low-cost production operations.

The goal is not process for its own sake. It is enough shared structure that engineers, product partners, and internal users can see what matters, what is blocked, and what has changed. My preferred tools are correspondingly practical: a scoped backlog, a decision log, an action owner, a release checklist, and a retrospective that changes the next cycle. When a process costs more attention than the problem it solves, I remove it.

I would welcome the chance to help CodePath's engineering team protect focus while improving delivery visibility and release confidence. I bring calm follow-through, technical curiosity, and a habit of treating documentation as part of the working system rather than the work after the work. Thank you for considering my application.

Sincerely,

Jamie Burkart
