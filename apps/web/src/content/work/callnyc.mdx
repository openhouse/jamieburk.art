## One-line summary

An archived civic-data prototype that translated NYC Council constituent-services open data into resident-facing issue pages and next-step guidance.

## Snapshot

- **Role:** Civic Tool Builder & Product Lead
- **Years:** 2015-2016
- **Context:** Civic-data hackathon and public-facing open-data prototype
- **Tools / systems:** CouncilStat-style data, issue pages, civic guidance, prototype web interface
- **Main outputs:** Public issue pages and resident guidance
- **Transferable strengths:** Civic-data translation, product framing, public information architecture
- **Status / caveat:** Archived prototype; not an official or current City Council service

## Context

Open data is often technically available before it is usable by residents. The useful product question was how to turn constituent-services data into guidance that could help someone understand a common issue and see possible next steps.

## What was unclear

The raw data did not answer the resident's question by itself. People needed categories, issue framing, plain-language guidance, and a public interface that treated data as a starting point for action rather than an endpoint.

## What I built / coordinated / documented

I built a civic-data prototype with public issue pages and resident-facing guidance. The work translated constituent-services open data into a more navigable experience and made the boundaries of the prototype clear.

## What became usable

Residents and civic collaborators could see a model for turning public data into issue-specific guidance. The prototype demonstrated a pattern: open data plus careful framing can become a practical public tool.

## How people used it

The project functioned as a civic prototype and proof of concept. It showed how public data might support resident guidance while making clear that the tool was not an official service.

## Outcomes

- Built after a New York City Council civic-data hackathon.
- Translated constituent-services open data into resident-facing issue pages.
- Created a public-facing prototype with explicit archival and official-service disclaimers.
