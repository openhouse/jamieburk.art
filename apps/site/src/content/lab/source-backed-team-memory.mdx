## The pattern

Source-backed team memory is a documentation practice for teams that need more than notes and less than a giant archive.

The useful unit is a decision, claim, source, or next action that future collaborators can trace. The safety boundary matters as much as the recall layer: some materials can be public, some can be summarized, and some should stay protected.

## What it helps with

- Onboarding new collaborators without repeating every meeting.
- Reconstructing why decisions were made.
- Separating public claims from private context.
- Making handoffs easier after launches, campaigns, or transitions.
- Keeping uncertainty visible instead of burying it.

## What it is not

It is not a chatbot over private history, a raw transcript dump, or a replacement for consent. It is a careful structure for turning source material into useful memory while keeping boundaries intact.
