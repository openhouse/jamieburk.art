# Warren Sack Lens

This eval tests whether the portfolio makes Jamie's recursive relational
reasoning and movement across representations legible. It distinguishes data
from relationships, prototypes from deployed systems, and direct authorship
from co-designed work while keeping people visible as agents in the system.

The fixture uses public-safe summaries only. Raw educational records, grades,
identifiers, correspondence, contact details, and unapproved images remain
outside the repository.

Run:

```bash
npm run evals:warren-sack
```

The checker validates the contract, exact About-page projection, Knowledge Bank
support, independent judge artifacts, artifact hashes, distinct read-only judge
sessions, and two consecutive perfect non-regressing rounds.
