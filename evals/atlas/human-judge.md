# Atlas human judge contract

These criteria cannot be certified by an implementation agent. Each requires a
named human reviewer, distinct evidence, a written rationale, and an explicit
pass or fail. A missing review remains pending and blocks an Atlas release
certification without failing deterministic repository checks.

## Social-mechanism fidelity

Pass only when the reviewed pages distinguish participation, facilitation,
authorship, hosting, sponsorship, response, institutional use, and causation.
Do not infer endorsement or sole authorship from proximity in the graph.

## Situated-experience fidelity

Pass only when artistic practice, embodiment, atmosphere, voice, and lived
experience remain legible alongside operational structure. Do not award a pass
for merely adding aesthetic language or invoking a named scholar.

## No-context reader navigation

Give a reader a project page without explaining Atlas. Pass only when the
reader can locate relevant evidence, collaborators, methods, corrections, and
open questions and can explain what is known, uncertain, and protected.
