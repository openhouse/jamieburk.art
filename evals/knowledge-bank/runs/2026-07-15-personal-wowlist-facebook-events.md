# Personal and WOW List Facebook event archive production

Date: 2026-07-15

## Objective

Disposition the complete event populations visible through Jamie Burkart's
authenticated personal Facebook surfaces and the WOW List Page event surface;
retain selected public-safe event plot points, posted research routes, and
source leads; and strengthen the knowledge bank without exposing a social graph
or forcing reserve-depth material onto the portfolio.

## Population control

- Jamie's profile event surface yielded 502 distinct event IDs in each of three
  terminal traversals. The third pass used 88 expansion attempts and stopped
  after 12 stable passes.
- The hosted-events surface yielded 21 past-event records. Eighteen overlap the
  profile population, producing a union of 505 distinct current IDs.
- Twenty profile cards displayed `Event by Jamie Burkart`; 482 displayed
  another host. The aggregate public-safe census preserves year, source
  surface, recovery status, and primary form without retaining event IDs,
  titles, URLs, locations, guest data, or the other displayed host names.
- The WOW List Page event surface displayed zero records while authenticated as
  the Page. Prior bounded archival checks did not recover a historical event
  population. This is a non-recovery result, not proof that no WOW List event
  page ever existed.

## Maturation

The pass adds two intake records, 19 source records, 17 atomic observations,
five bounded claims, and two research inquiries. Nine selected public event
pages preserve representative practice across 2006-2017. Three destinations
posted from the 2007 `Micropop: Nation-Scenes` event are retained as source
routes rather than automatic corroboration. A 2016 KCUR article independently
supports public-history context for the 8th Street Tunnel.

The selected event pages support the literal displayed host label and the
public event form. They do not establish sole authorship, production
responsibility, attendance, unique reach, endorsement, causality, or a complete
collaborator and participant roster.

The visible website gains no new event-practice claim. Existing Sunday Dinner
proof notes now identify public event pages supporting the 100th dinner, the
eight-week New York City rotation, and a civic sign-making potluck. The broader
practice remains bank-only reserve depth.

## Recursive hill climb

### Iteration 1: population completeness

The first control reconciled the 502 profile IDs, 21 hosted records, 18-record
overlap, 505-record union, and zero displayed WOW List Page events.

### Iteration 2: independent live verification

A fresh authenticated traversal reproduced all 502 profile IDs exactly,
recovered all 21 hosted records, and reproduced the zero-record WOW List Page
surface. The control now requires the exact repeated-set result.

### Iteration 3: public-safety minimization

The public-safe census was reduced to twenty anonymous displayed-Jamie slots.
Checks reject row-level Facebook IDs, long numeric identifiers, URLs, private
paths, guest identities, sole-author metadata, and accidental hiring-page
projection.

### Iteration 4: claim and source boundaries

Selected event sources were separated from association counts; posted URLs were
modeled as routes; WOW List absence remained `not-recovered`; and claims were
given explicit anti-claims, boundaries, evidence, review owners, and bank-only
projections.

### Iteration 5: evaluator diagnostics

The new criterion was decomposed into named invariants for control arithmetic,
live reverification, graph shape, source scope, atomicity, maturation,
composition, reporting, and safety. This exposed and corrected a punctuation
error in the exact Facebook host-label citation instead of weakening the test.

## Stop condition

- `npm run check:knowledge-evals`: 5/5 across 20 criteria.
- `npm run test:knowledge-evals`: 153/153 tests passed.
- `npm run check`: passed under Node 26 after a clean lockfile install.
- `npm run preflight:staging`: passed with staging noindex configuration.
- `npm run preflight:production`: passed with explicit production index
  configuration.
- `npm audit --omit=dev --audit-level=high`: passed; two moderate transitive
  PostCSS advisories remain in Next.js and require a breaking downgrade for the
  suggested automated fix.

All deterministic criteria are met. Further iteration would add reader burden
or disclosure without improving the present archival objective, so the
recursive pass stops here.
