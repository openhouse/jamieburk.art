# Portfolio-effectiveness blind-spots hill climb

Date: 2026-07-15

## Objective

Turn seven high-priority portfolio blind spots into durable evals, improve every
criterion as far as the present public-safe repository evidence permits, and
keep work that requires real readers, collaborators, rights holders, external
outcome evidence, or an exact deployed commit visible as an external gate.

## Initial audit estimate

No automated portfolio-effectiveness evaluator existed before this pass. The
starting values below are therefore a structured audit estimate, not a measured
evaluator result:

| Criterion | Estimated start | Main gap |
| --- | ---: | --- |
| Hiring-reader comprehension | 3 | No reusable reader tasks or human-session protocol |
| Collaborator corroboration | 1 | Important role-attribution gaps had no prioritized request queue |
| End-to-end operating narratives | 3 | Strong project material was not normalized into complete causal sequences |
| Current 2024-2026 evidence | 2 | Recent practice was present but not gathered into one bounded evidence layer |
| Consent-cleared visual proof | 3 | One cleared artifact existed; the next rights-review lanes were not explicit |
| Exact-SHA production evidence | 3 | Release actions existed, but no evidence schema distinguished a branch pass from a deployed commit |
| Evaluation and source maintenance | 2 | No owner, cadence, complexity budget, or retirement rule covered these concerns together |

## Iteration 1: Define truthful score anchors

Seven weighted criteria now distinguish repository-verifiable progress from
outside-world completion. Every criterion has minimum, strong, and excellent
anchors. A score of 5 is impossible without the corresponding direct evidence.

Anti-gaming rules prohibit these substitutions:

- LLM or browser review for a real hiring-reader session;
- Jamie's memory or an AI archival note for collaborator corroboration;
- a proposal for delivered client work;
- a pending image for a rights-cleared artifact;
- a feature-branch check for exact-SHA production evidence;
- an evaluator's assertion for independent evidence about itself.

## Iteration 2: Create the first usable evidence layer

The pass added:

- five timed reader-task cases spanning hiring, implementation, civic-tech,
  recruiter, and collaborator-care perspectives;
- five prioritized collaborator-proof requests with role gaps, permission
  states, and a reusable question set;
- complete operating sequences for CallNYC, KC Town Hall, and NYC Artist
  Coalition / Commercial Rent Stabilization;
- three bounded 2024-2026 practice records;
- one cleared visual artifact and five rights-aware selection lanes;
- an exact-SHA evidence protocol that refuses to claim a candidate or release
  before one exists;
- ownership, review cadences, source-health rules, a ten-criterion complexity
  budget, and retirement rules.

## Iteration 3: Add deterministic and adversarial verification

The evaluator resolves every referenced public route, proof, claim, source, and
repository file. Eleven regression tests exercise the scoring and rejection
boundaries, including malformed URLs, private paths, unknown evidence,
open-ended self-certification, and SHA mismatch.

The root `npm run check` now runs the portfolio-effectiveness check and tests
alongside citation, launch, knowledge-bank, application, safety, and route
checks.

minimum:

| Collaborator corroboration | 3 | Five prioritized requests; no collaborator notes claimed |

| Current 2024-2026 evidence | 4 | Three normalized records; external outcomes remain open |
| Consent-cleared visual proof | 3 | One cleared artifact and five review lanes |

## External gates

Five gates remain because they cannot be completed inside the repository alone:

1. Run five privacy-safe sessions with real hiring readers.
2. Request, receive, permission, and normalize five collaborator proof notes.
3. Add external outcome corroboration to three recent-practice records.
4. Clear decisive visual evidence for two more flagship cases.
5. Attach staging, accessibility, approval, Docker, and production evidence to
   one exact SHA.

## Stop condition

The local hill climb stops only after all seven minimums and the weighted target
pass twice consecutively. The five external gates remain first-class work; they
are not failures to hide and may not be removed merely to raise the score.
