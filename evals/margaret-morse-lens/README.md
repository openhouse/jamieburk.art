# Margaret Morse Lens

This eval protects a dimension that a conventional hiring rubric can erase:
Jamie thinks and works through embodied situations, sustained tending, material
experiments, atmosphere, and participation. It asks the portfolio to make that
practice legible without treating art as merely a precursor to administration.

The fixture uses public-safe summaries only. Raw educational records,
recommendation captures, grades, identifiers, correspondence, contact details,
and unapproved participant material remain outside the repository.

Run:

```bash
npm run evals:margaret-morse
```

The checker validates the contract, exact About-page projection, Knowledge Bank
support, independent judge artifacts, artifact hashes, distinct read-only judge
sessions, and two consecutive perfect non-regressing rounds.
